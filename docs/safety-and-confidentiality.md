# Safety and Confidentiality

## v1 readiness 安全边界

试点前请阅读：

- [数据处理与样例脱敏指南](data-handling-and-anonymization-guide.md)
- [公开仓库与私有部署边界](public-vs-private-deployment-boundary.md)
- [私有试点指南](private-pilot-guide.md)

公开仓库仍不得保存真实客户资料、真实案件材料、真实合同、真实个人信息、真实监管材料、真实员工信息、真实交易材料、密钥、token、API key、Cookie 或私有系统配置。当前项目仍不接入真实 MCP 或生产系统。

Codex for Legal CN 是法律工作流模板项目，不提供法律意见。所有输出必须作为“律师审阅用草稿”处理。

## 公开仓库边界

公开仓库只能存放模板、流程、检查清单、评测方法、连接器占位文档和明显虚构样例。不得提交真实客户资料、真实案件材料、真实合同、真实证据、真实交易文件、个人信息、商业秘密、密钥、token、Cookie 或私有连接配置。

## 律师复核

任何对客户、法院、仲裁机构、监管机构、交易对手发送、提交、签署或依赖的内容，必须由合格法律专业人士复核。AI 输出不得直接作为法律意见。

## 个人信息处理

处理个人信息时应遵循最小必要原则。示例材料必须删除或替换身份证号、手机号、住址、银行账户、健康信息、未成年人信息、生物识别信息等敏感内容。涉及真实个人信息、第三方工具、出境或跨客户共享时，应由负责律师或合规负责人确认。

## 来源和引用

不得虚构法律依据、法规名称、条文编号、案例名称、法院观点或监管口径。无来源时写“待律师核验”。输出应区分事实来源、法律来源、客户提供材料和律师判断。

## 本地、私有和公开环境

| 环境 | 使用边界 |
| --- | --- |
| 本地环境 | 可处理授权范围内材料，但不得误提交 |
| 私有仓库 | 可放内部模板和脱敏评测集，需权限控制 |
| 公开仓库 | 只放通用模板、流程和虚构样例 |

## 连接器安全

MCP 连接器默认只读、最小权限、按事项隔离。所有写回、发送、签署、提交或删除动作必须人工确认。
