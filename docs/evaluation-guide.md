# Evaluation Guide

本指南说明如何用脱敏历史项目评测三个核心插件。所有评测材料必须虚构或充分脱敏。

## 评测准备

1. 选择已结案或已完成项目，删除真实客户、对方、个人、金额、地址、账号和商业秘密。
2. 保留足够结构信息，例如条款类型、文件类型、事件顺序和证据关系。
3. 由负责律师准备参考答案或评分要点。
4. 记录使用的 skill、profile 版本和模板版本。

## 合同审查评测

- 合同审查遗漏率：关键风险是否被识别。
- 风险分级一致性：低/中/高/红旗是否符合团队口径。
- 修改建议可用性：是否能被律师快速改写。
- 客户事项识别：商务确认事项是否清楚。

## 并购尽调评测

- 问题提取准确率：股权、合同、资质、税务、劳动、争议等领域是否覆盖。
- 重大性判断：是否符合项目阈值。
- 交易文件影响：是否能连接交割条件、披露或交割后义务。
- 来源可追踪：是否保留文件和引用来源占位。

## 诉讼案件评测

- 时间线完整性：关键日期、事件和证据来源是否完整。
- 证据目录质量：证明目的和三性提示是否可复核。
- 争点表可用性：我方主张、对方可能主张和证明难点是否清楚。
- 庭前准备可用性：是否帮助律师减少整理时间。

## 复核耗时节省

建议记录律师从收到 AI 草稿到完成可用工作底稿的时间，并与人工从零整理时间比较。不要只看生成速度，要看遗漏、误判和返工成本。
