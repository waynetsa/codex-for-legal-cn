# Evaluation Guide

评测应使用脱敏历史项目或完全虚构样例，不得使用真实客户资料、真实案件材料、商业秘密或个人信息。

## 合同审查遗漏率

比较 skill 输出与律师审查结果，统计重大风险、中等风险和格式问题的遗漏情况。

## 尽调问题提取准确率

评估是否准确识别资料缺失、重大合同、资质许可、诉讼仲裁、行政处罚、税务和劳动风险初筛事项。

## 诉讼事实时间线完整性

评估关键日期、事实来源、证据编号、事实状态和矛盾点是否完整。

## 输出格式可用性

检查输出是否便于复制到工作底稿、项目台账或律师备忘录，是否区分事实、风险、建议和待确认事项。

## 律师复核耗时节省

记录律师从接收材料到完成可用初稿的耗时变化。该指标只评价效率，不评价法律结论正确性。
