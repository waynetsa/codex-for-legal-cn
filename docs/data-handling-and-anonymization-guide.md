# Data Handling and Anonymization Guide

本指南用于公开仓库和私有试点的数据处理边界。项目公开仓库只允许模板、虚构样例、明显脱敏样例、检查清单和说明文档。

## 公开仓库允许

- 虚构样例。
- 明显脱敏样例。
- 模板。
- 检查清单。
- 说明文档。

## 公开仓库禁止

- 真实客户名称。
- 真实案件材料。
- 真实合同。
- 真实员工信息。
- 真实个人信息。
- 真实监管材料。
- 真实交易资料。
- 真实内部批注。
- 密钥、账号、token、API key、Cookie 或私有系统配置。

## 脱敏步骤

1. 替换主体名称。
2. 替换人名。
3. 替换时间。
4. 替换金额。
5. 替换地点。
6. 替换合同编号。
7. 替换项目名称。
8. 删除联系方式。
9. 删除身份证件信息。
10. 删除银行账户。
11. 删除系统 URL。
12. 删除文件元数据。

## 脱敏后仍需检查

- 多个字段组合后是否仍能识别真实主体。
- 时间线是否暴露真实交易或案件。
- 金额、地点、岗位、项目代号是否具有唯一性。
- 附件、图片、批注、修订记录是否残留信息。
- 文件名、路径、作者、创建时间等元数据是否暴露信息。

## 仍不应放入公开仓库的情况

- 即使脱敏，材料仍高度可识别。
- 客户未授权。
- 涉及未公开交易、监管调查、敏感劳动争议、重大案件或个人敏感信息。
- 脱敏质量无法由律师或合规负责人确认。

## 私有环境使用真实材料的前提

- 客户或内部授权。
- 访问控制。
- 用户权限。
- 日志。
- 审计。
- 客户隔离。
- Matter 隔离。
- 保密审批。
- 数据留存和删除策略。
