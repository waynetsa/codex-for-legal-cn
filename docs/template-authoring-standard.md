# Template Authoring Standard

本标准用于维护 8 个法律工作流插件的 `templates/`。模板是律师、法务、合规或业务负责人可编辑的内部草稿，不是正式交付物。

## 模板定位

- 模板可以作为内部工作底稿、事实整理表、风险清单、审查意见草稿或提纲。
- 模板不得直接作为正式法律意见、正式合同修改稿、正式监管回复、正式诉讼材料、正式员工通知、正式隐私政策、正式投诉或正式对外公告。
- 模板输出必须保留“律师审阅用草稿”定位。

## 每个模板建议包含

- 草稿标识。
- 使用场景。
- 输入材料范围。
- 输出边界。
- 律师复核要求。
- 待补材料。
- 待核验依据。
- 风险等级。
- 升级事项。

## 统一免责声明

模板开头或页脚应引用 `shared/templates/common-disclaimer-footer.md` 的统一免责声明。对外沟通、监管、诉讼、劳动、人事、隐私、平台投诉和交易文件类模板，应在开头显著提示不得直接使用。

## 正式文件边界

正式文件边界参见 `shared/templates/formal-document-boundary.md`。模板可以作为正式文件起草前的底稿，但必须经过合格律师或负责人员复核。

## 宽表处理

Markdown 表格过宽时，应拆分为：

- 核心事实表。
- 风险表。
- 待补材料表。
- 决策事项表。
- 升级事项表。

不要为了排版删除关键字段。

## CSV 与 Markdown

- CSV 适合批量记录、导入表格和后续评测。
- Markdown 适合律师阅读、评审、复制和修改。
- 如果 CSV 字段很多，建议提供 Markdown 分段版本。

## 避免正式法律意见口吻

使用：

- 初步提示。
- 基于现有材料。
- 待律师核验。
- 建议补充。
- 建议升级复核。

避免：

- 确认合法。
- 确认违法。
- 必然败诉。
- 必然被处罚。
- 可直接发送。
- 无需律师复核。
