# Usage for Admins

本文面向律所知识管理、IT 和合规负责人。

## 权限

建议按团队、业务线、项目和客户设置访问权限。真实客户材料、案件材料和商业秘密不应进入公开仓库。

## 资料脱敏

建立脱敏规则，至少覆盖客户名称、交易对手、自然人信息、联系方式、证件号码、账户信息、商业秘密和未公开交易信息。

## 模板管理

模板应由业务负责人维护版本。每次模板更新应记录修改原因、适用场景、负责人和生效日期。

## 评测

用脱敏历史项目或完全虚构样例评估技能。评测指标包括遗漏率、准确率、输出格式可用性、律师复核耗时和升级判断一致性。

## 版本更新

插件更新前建议在测试环境运行评测。重大变更应通知使用团队，并保留回滚路径。
