# Usage for Lawyers

本项目帮助律师生成可复核的工作底稿，而不是替代法律判断。

## 使用前

- 先脱敏材料。
- 明确适用法域；默认中国大陆法律语境。
- 明确客户角色、交易或案件阶段、输出用途和截止时间。
- 先运行对应插件的 `cold-start-interview`。

## 上传材料

仅使用脱敏材料。不要上传真实客户名称、身份证件、联系方式、商业秘密、未公开交易信息或完整案件材料到公开仓库。

## 审阅输出

所有法律内容必须视为“律师审阅用草稿”。律师应重点检查：

- 事实是否与材料一致。
- 风险是否遗漏或夸大。
- 法律依据是否真实、准确、现行有效。
- 建议是否符合客户目标、谈判位置和执业规范。
- 是否需要合伙人、项目负责人或合规负责人复核。

## 改成正式法律文件

Codex 输出只能作为草稿素材。正式发送、提交、签署或依赖前，必须由合格法律专业人士复核，并根据律所格式、客户授权和项目口径改写。
