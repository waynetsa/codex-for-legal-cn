# Commercial Cold-Start Result

> 律师审阅用草稿。不得直接对外发送、提交、签署或作为法律意见使用。

## profile 建议结构

- 团队信息：星湾商事合同组（虚构）。
- 常见客户：科技公司采购方、SaaS 使用方、平台运营方。
- 常见合同：服务、技术、SaaS、授权、合作、框架协议。
- 我方常见身份：采购方、服务接受方、平台方。
- 适用法域：默认中国大陆；具体法律依据待律师核验。
- 风险偏好：中等偏保守。
- 不可接受条款：无数据处理安排、责任上限过低、未授权签章、单方默示验收。
- 可让步条款：合理通知方式、非核心供应商工具知识产权保留。
- 必须升级事项：红旗、高风险、数据/个人信息、管辖重大偏离、自动续约退出窗口不足 30 日。
- 输出格式：风险表、修改方向、替代表述占位、客户决策事项、升级事项。

## 负责律师确认

请主办律师确认风险等级、升级事项和客户沟通口径；负责合伙人确认红旗风险处理方式。
