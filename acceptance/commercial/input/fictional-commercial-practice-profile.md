# 虚构商事合同 Practice Profile

> 律师审阅用草稿。本 profile 完全虚构。

- 团队名称：星湾商事合同组（虚构）。
- 客户类型：成长型科技公司、SaaS 采购方、平台运营方。
- 风险偏好：中等偏保守；涉及数据、责任上限、自动续约、管辖偏离时从严处理。
- 不可接受条款：无数据返还删除机制；责任上限低于 6 个月服务费；单方默示验收；未经授权电子签章。
- 可让步条款：普通通知方式、合理违约金、非核心工具的供应商知识产权保留。
- 必须升级事项：红旗风险、责任上限异常、数据或个人信息风险、管辖重大偏离、自动续约退出窗口不足 30 日。
- 输出风格：表格优先，短句说明，便于律师复制到审查备忘录。
- 复核人角色：主办律师、负责合伙人、客户业务负责人，均为角色，不写真人姓名。
