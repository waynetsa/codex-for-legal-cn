# 端到端 Alpha 验收

本目录用于 `v0.1.0-alpha` 的端到端使用路径验收，不存放真实材料。所有输入、输出、评测记录均为虚构或明显脱敏样例，不包含真实客户、真实案件、真实合同、真实交易、真实个人信息、密钥、token 或真实 MCP 配置。

## 三条验收路径

1. 合同审查路径：验证 `cn-commercial-legal` 是否能完成 cold-start、合同审查、偏离清单和续约风险检查。
2. 并购尽调路径：验证 `cn-corporate-legal` 是否能完成资料室文件表格化审阅、问题提取、交割清单和披露清单。
3. 诉讼案件路径：验证 `cn-litigation-legal` 是否能完成案件 intake、事实时间线、证据目录、争点表、庭前准备和案件周报。

## 每条路径包含

- 虚构输入材料。
- 虚构 practice profile。
- skill 输出结果。
- 评测表。
- 问题发现。

本轮目标是验证 `v0.1.0-alpha` 的真实可用性。所有输出均为“律师审阅用草稿”，不得作为正式法律意见、客户交付件、诉讼提交材料或交易文件直接使用。
