# cn-regulatory-legal Acceptance Plan

> 律师审阅用草稿；本目录目前仅为计划，不包含完整端到端验收结果。

`cn-regulatory-legal` 已进入 MVP 开发。本轮只补插件能力、模板、references、eval guidance 和计划验收路径，不做完整端到端 acceptance，不发布新 tag，不接入真实 MCP 或真实监管数据库。

## 后续计划验收材料

后续将使用虚构监管问询和整改场景，覆盖企业客户、律所合规团队、常年法律顾问、专项整改、监管问询响应、政策影响分析和管理层合规报告。

所有材料必须虚构或明显脱敏，不得使用真实监管问询、真实处罚决定、真实整改报告、真实内部调查材料、真实客户经营数据或真实个人信息。

## 计划验收路径

- cold-start
- regulatory-change-impact-brief
- compliance-obligation-map
- regulatory-inquiry-response-outline
- administrative-penalty-risk-triage
- remediation-plan-builder
- management-compliance-briefing

## MVP 边界

- 输出均为“律师审阅用草稿”。
- 不提供法律意见。
- 不得直接作为正式监管提交材料、正式整改报告、正式对外公告或正式合规结论。
- 法律依据、监管口径、期限和事实来源均写“待律师核验”。
