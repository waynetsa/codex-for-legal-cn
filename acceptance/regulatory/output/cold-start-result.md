# Regulatory Cold-start Result

> 律师审阅用草稿  
> 本材料基于虚构验收样例生成  
> 不构成法律意见

## 团队画像摘要

监管合规、企业合规、争议解决和常年法律顾问联合团队，服务虚构内容社区、会员营销和轻量游戏平台的监管合规事项。

## 基础配置

| 项目 | 内容 |
|---|---|
| 服务对象 | 企业法务、合规、风控、审计、董办、管理层、业务部门、律所合规团队 |
| 行业类型 | 虚构内容社区、会员营销、轻量游戏平台 |
| 常见监管主题 | 广告营销、平台责任、内容合规、数据合规、消费者权益、价格合规、产品质量 |
| 常见监管材料类型 | 问询函、检查通知、整改通知、处罚告知、监管函、合规自查表、内部整改报告 |
| 风险偏好 | 对正式监管回复、整改承诺、价格展示和消费者权益事项采取偏审慎口径 |

## 必须升级事项

| 事项 | 升级原因 | 复核角色 |
|---|---|---|
| 正式监管回复或整改报告 | 可能形成对外提交材料 | 律师、合规负责人、管理层 |
| 行政处罚或监管调查风险 | 涉及重大法律后果 | 合伙人、专项律师 |
| 业务暂停或对外公告 | 涉及管理层决策和声誉风险 | 管理层、法务 |
| 客户经营数据、个人信息、商业秘密 | 涉及保密和数据合规 | 律师、数据安全组 |

## 核验和审批规则

| 规则 | 内容 |
|---|---|
| 法规来源核验规则 | 法律依据、监管口径、期限、程序和公开信息来源均写“待律师核验” |
| 事实核验规则 | 区分已确认事实、客户陈述、待补事实、待提交材料和律师待核验事项 |
| 监管回复审批规则 | 内部提纲可协作起草；正式提交前必须由律师、合规负责人和管理层复核 |
| 整改跟踪规则 | 每项整改列明责任部门、责任人角色、交付物、截止时间、验收标准和留痕材料 |
| 管理层报告偏好 | 一页摘要、短表、30/60/90 天行动计划 |

## 律师复核节点

- 监管回复范围、截止时间和提交材料。
- 是否涉及行政处罚或监管调查风险。
- 整改承诺是否可能形成持续义务。
- 管理层是否需要暂停业务或配置专项预算。
