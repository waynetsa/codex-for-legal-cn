# 监管问询响应内部提纲结果

## 监管事项摘要

| 字段 | 内容 |
| --- | --- |
| 来函或通知类型 | 虚构监管问询函 |
| 要求回复事项 | 广告营销、会员规则、数据使用、投诉处理和供应商管理情况 |
| 截止时间 | 待律师核验 |
| 客户已有事实 | 已有部分制度、邮件审批、客服记录和供应商合同 |
| 待补事实 | 数据流向、营销投放全量清单、投诉闭环、供应商处理边界 |

## 材料准备和内部分工

| 回复事项 | 客户已有事实 | 待补事实 | 待提交材料清单 | 内部分工 | 回复口径风险 |
| --- | --- | --- | --- | --- | --- |
| 广告营销 | 有部分审批邮件 | 全量投放清单不完整 | 素材、审批记录、投放记录 | 市场 / 法务 | 不能承诺所有历史素材均已合规 |
| 会员规则 | 有现行页面 | 旧版规则和通知记录待补 | 页面版本、用户通知、投诉记录 | 产品 / 客服 | 规则变更口径需统一 |
| 数据使用 | 有流程图草稿 | 授权、用途和第三方处理待核验 | 数据流向表、权限表 | 数据 / 合规 | 涉及数据合规，应升级 |

## 不宜直接回复事项

| 事项 | 不宜直接回复原因 | 建议处理方式 | 是否升级 |
| --- | --- | --- | --- |
| “全部业务均合规”类表述 | 事实和依据未全面核验 | 改为基于已核验事实分项说明 | 是 |
| “立即完成全部整改”类承诺 | 可能超出履行能力 | 先形成分阶段整改计划 | 是 |
| 涉及数据处理或第三方服务细节 | 材料尚不完整 | 待补数据流和供应商材料 | 是 |

## 正式提交前禁止项

| 禁止项 | 检查状态 | 责任角色 |
| --- | --- | --- |
| 未经律师复核直接提交 | 未完成 | 法务负责人 |
| 未经事实负责人确认关键事实 | 未完成 | 业务负责人 |
| 未经管理层批准作出重大整改承诺 | 未完成 | 管理层 |
| 引用未经核验法规、期限或监管口径 | 未完成 | 经办律师 |

## 正式提交前审批链

| 环节 | 责任角色 | 输出物 | 是否完成 |
| --- | --- | --- | --- |
| 事实核验 | 市场、产品、客服、数据负责人 | 事实确认表 | 待完成 |
| 材料核验 | 法务 / 合规 | 材料清单 | 待完成 |
| 法律复核 | 经办律师 / 合伙人 | 律师复核意见 | 待完成 |
| 管理层批准 | 管理层角色 | 提交授权记录 | 待完成 |

## 律师复核清单、管理层决策和升级事项

| 类别 | 内容 |
| --- | --- |
| 律师复核清单 | 回复口径、附件、法律依据、期限、整改承诺、对外披露影响，均待律师核验 |
| 管理层决策事项 | 是否暂停高风险营销活动、是否投入资源补齐数据和供应商台账 |
| 升级事项 | 事实未核验、材料不完整、可能涉及处罚或整改承诺、可能影响对外披露 |
