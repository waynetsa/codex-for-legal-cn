## 场景摘要

| 项目 | 内容 |
| --- | --- |
| 场景描述 | 澄明智造拟上线云枢 AI 办公与客服助手 |
| 使用主体 | 法务、市场、客服、研发、人力、销售、管理层 |
| 输入 | 公开资料、内部资料、合同资料、客户资料、员工资料、个人信息、商业秘密、源代码、财务数据 |
| 处理 | AI SaaS、大模型 API、文档问答、代码辅助、客服回复 |
| 输出 | 内部参考、客户交付、对外发布、自动回复、管理决策辅助 |
| 使用后果 | 可能影响客户沟通、市场发布、合同理解、研发资料保护和管理层决策 |
