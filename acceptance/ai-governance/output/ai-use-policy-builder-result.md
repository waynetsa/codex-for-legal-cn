# AI Use Policy Builder Result

> 律师审阅用草稿  
> 本材料基于虚构验收样例生成  
> 不构成法律意见

## 制度框架

| 模块 | 内容草稿 | 复核要求 |
| --- | --- | --- |
| 适用主体 | 员工、外包人员、业务部门负责人、IT/安全/法务/合规审批人员 | 管理层确认 |
| 可用场景 | 公开资料摘要、虚构样例、内部非敏感培训草稿 | 部门负责人复核 |
| 限制使用场景 | 合同摘要、客服回复、营销对外发布、代码辅助 | 法务、合规、IT/安全复核 |
| 禁止使用场景 | 未审批客户资料、案件材料、个人信息、商业秘密、源代码、财务数据输入公开工具 | 律师和管理层复核 |

## 禁止输入清单

| 禁止输入内容 | 示例 | 例外审批 |
| --- | --- | --- |
| 客户秘密 | 客户名单、客户沟通、客户合同 | 律师、法务、合规审批 |
| 案件材料 | 证据、诉讼策略、代理意见 | 原则禁止公开工具 |
| 未公开交易资料 | 尽调资料、交易结构、报价 | 私有环境和审批 |
| 商业秘密 | 产品路线图、未公开价格 | 管理层和法务审批 |
| 个人信息 | 客户联系人、员工资料 | 数据合规审批 |
| 员工敏感信息 | 绩效、处分、健康相关信息 | 原则禁止公开工具 |
| 源代码 | 内部代码、接口文档 | 安全和研发负责人审批 |
| 财务数据 | 成本、预算、预测 | 财务和管理层审批 |
| 账号密码或密钥 | token、API key、Cookie | 禁止输入 |
| 未经授权第三方作品 | 图片、音乐、代码、文本 | 权利核验 |

## 审批矩阵

| 使用场景 | 业务负责人 | 法务 | 合规 | IT/安全 | 数据保护负责人 | 管理层 |

## 人工复核清单

- 客户交付：需律师/法务复核。
- 外部发布：需业务负责人和法务复核。
- 自动回复：上线前需管理层批准，输出需抽检。
- 自动决策：原则暂缓，需专项评估。
- 合同或法律材料输出：不得直接作为正式法律意见。

## 记录留痕和审计要求

- 工具名称、账号、使用部门、输入数据类型、输出用途、审批记录、复核记录、异常事件。
