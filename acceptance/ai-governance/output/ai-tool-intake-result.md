# AI Tool Intake Result

> 律师审阅用草稿  
> 本材料基于虚构验收样例生成  
> 不构成法律意见

## 工具准入初筛表

| 字段 | 结论草稿 |
| --- | --- |
| 工具名称 | 云枢 AI 办公与客服助手 |
| 使用部门 | 法务、市场、客服、研发、人力、销售 |
| 使用目的 | 文档摘要、客服回复建议、营销文案、代码辅助、合同摘要 |
| 处理数据类型 | 公开资料、内部资料、合同资料、客户资料、员工资料、个人信息、商业秘密、源代码、财务数据 |
| 是否涉及个人信息 | 是，需脱敏和审批 |
| 是否涉及客户秘密或商业秘密 | 是，高风险 |
| 是否涉及跨境或第三方处理 | 是，虚构设定为部分日志可能境外处理，待律师核验 |
| 是否用于自动决策或对外输出 | 客服自动回复和营销发布涉及对外输出；管理决策辅助需复核 |
| 是否需要供应商评估 | 是 |
| 初步风险等级 | 红旗，因客户数据训练、删除机制、审计权、分包和境外处理不清 |

## 审批角色

| 角色 | 是否需要 | 关注点 |
| --- | --- | --- |
| 安全 | 是 | 数据保护、权限、日志、供应商安全 |
| IT | 是 | 部署、账号、系统接入、审计 |
| 法务 | 是 | 合同条款、责任、权属、合规边界 |
| 合规 / 数据合规 | 是 | 个人信息、跨境、第三方处理 |
| 业务负责人 | 是 | 使用必要性、上线节奏、人工复核 |

## 禁止上线条件

- 供应商未明确客户数据不得用于训练或模型改进。
- 删除机制、审计权、分包和境外处理边界未明确。
- 未建立禁止输入内容清单和员工培训。
- 客服自动回复缺少人工复核。

## 待补材料

- 完整服务条款、DPA、隐私政策、安全白皮书、SLA、分包清单、数据流转图、删除机制说明、审计说明。

## 升级事项

| 事项 | 升级对象 | 原因 |
| --- | --- | --- |
| 数据训练条款不清 | 合伙人、法务负责人、管理层 | 红旗风险 |
| 客服自动回复 | 法务、合规、客服负责人 | 对外输出风险 |
| 源代码和合同摘要输入 | 安全、法务、研发负责人 | 商业秘密和客户资料风险 |

## 使用提醒

本结果不是正式供应商准入结论；需律师/合规/管理层复核后方可使用。
