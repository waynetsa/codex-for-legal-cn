# AI Tool Intake Result

> 律师审阅用草稿  
> 本材料基于虚构验收样例生成  
> 不构成法律意见

## 工具准入核心表

| 字段 | 结论草稿 |
| --- | --- |
| 工具名称 | 云枢 AI 办公与客服助手 |
| 工具类型 | AI SaaS + 大模型 API + 文档问答助手 |
| 部署方式 | 供应商云端 SaaS，部分 API 接入企业知识库 |
| 使用部门 | 法务、市场、客服、研发、人力、销售 |
| 使用目的 | 文档摘要、客服回复建议、营销文案、代码辅助、合同摘要 |
| 输入数据 | 公开资料、内部资料、合同资料、客户资料、员工资料、个人信息、商业秘密、源代码、财务数据 |
| 输出用途 | 内部参考、客户交付、对外发布、自动回复、管理决策辅助 |
| 是否对外输出 | 是，客服和市场场景涉及 |
| 是否处理个人信息 | 是，需脱敏和审批 |
| 是否处理客户资料或商业秘密 | 是，高风险 |
| 是否涉及第三方处理或境外服务 | 是，虚构设定为部分日志可能境外处理，待律师核验 |
| 是否使用员工个人账号 | 已出现，需立即停止 |
| 是否有供应商安全材料 | 不完整 |
| 是否有合同和隐私政策 | 有摘要，需完整版本 |

## 准入结论分级

| 结论 | 适用范围 | 下一步 |
| --- | --- | --- |
| 可低风险试用 | 公开资料、虚构资料、内部非敏感资料 | 部门备案，记录使用 |
| 条件性试用 | 普通内部资料和培训草稿 | 法务、IT、安全复核后试点 |
| 暂缓上线 | 客户资料、合同摘要、员工资料、代码辅助 | 补齐供应商材料和审批 |
| 禁止上线，待人工复核 | 客户数据训练不清、自动回复、源代码输入 | 管理层和律师复核 |

## 上线阶段建议

| 阶段 | 期限 | 复盘条件 | 退出条件 |
| --- | --- | --- | --- |
| 试点 | 30 天 | 无敏感数据输入、无对外输出、日志完整 | 出现客户资料或个人信息误输入 |
| 灰度上线 | 60 天 | 完成供应商条款整改和培训 | 审计缺失或高风险事故 |
| 正式上线 | 待定 | P1 风险清零且管理层批准 | 红旗事项未关闭 |

## 审批责任

| 角色 | 是否需要 | 关注点 |
| --- | --- | --- |
| 业务负责人 | 是 | 使用必要性、试点范围、人员管理 |
| 法务 | 是 | 合同、责任、权利归属、合规边界 |
| 合规 | 是 | 使用规则、对外输出、违规处理 |
| IT / 安全 | 是 | 部署、账号、权限、日志、安全材料 |
| 数据保护负责人或相当角色 | 是 | 个人信息、跨境、第三方处理 |
| 管理层 | 是 | 红旗事项和正式上线决策 |

## 禁止上线条件

- 供应商未明确客户数据不得用于训练或模型改进。
- 删除机制、审计权、分包和境外处理边界未明确。
- 未建立禁止输入内容清单和员工培训。
- 客服自动回复缺少人工复核。

## 待补材料

- 完整服务条款、DPA、隐私政策、安全白皮书、SLA、分包清单、数据流转图、删除机制说明、审计说明。

## 升级事项

| 事项 | 风险等级 | 升级对象 |
| --- | --- | --- |
| 数据训练条款不清 | 红旗 | 合伙人、法务负责人、管理层 |
| 客服自动回复 | 高 | 法务、合规、客服负责人 |
| 源代码和合同摘要输入 | 高 | 安全、法务、研发负责人 |

## 使用提醒

本结果不是正式供应商准入结论；需律师/合规/管理层复核后方可使用。
