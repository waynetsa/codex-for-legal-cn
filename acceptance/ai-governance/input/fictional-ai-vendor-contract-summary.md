# 虚构 AI 供应商合同摘要

> 明确虚构声明：本合同摘要完全虚构，仅用于验收，不对应任何真实供应商、真实服务、真实系统或真实合同。

## 合同基本信息

- 服务名称：云枢 AI 办公与客服助手
- 供应商：澜舟云算科技（虚构）
- 服务类型：AI SaaS + 大模型 API
- 部署方式：供应商云端 SaaS，部分功能通过 API 接入企业知识库。

## 数据和安全条款摘要

- 客户数据输入：员工可上传文档、客服工单、合同摘要和内部知识库材料。
- 客户数据是否用于训练：条款写明“供应商可使用服务数据改进模型和服务质量”，未明确排除客户内容。
- 数据保留期限：默认保留 180 天日志和输入输出记录。
- 数据删除机制：客户可申请删除，但供应商未承诺具体完成期限。
- 安全措施：传输加密、账户权限、基础隔离，未提供详细安全审计报告。
- 访问控制：支持管理员权限，但未提供细粒度部门隔离说明。
- 日志记录：记录用户、时间、输入摘要、输出摘要和调用量。
- 审计权：客户无现场审计权，仅可要求供应商提供年度合规说明。
- 分包商或第三方服务：供应商可使用第三方云和模型服务，名单可变更。
- 跨境或境外处理提示：虚构设定为部分日志分析服务可能在境外云资源完成，需进一步确认。

## 输出和责任条款摘要

- 输出内容权属：条款称输出归客户使用，但供应商不保证输出不侵犯第三方权利。
- 第三方侵权责任：供应商仅在其故意或重大过失范围内承担有限责任。
- 保密义务：供应商承诺保密，但例外范围较宽。
- SLA 和服务可用性：月度 99.0%，仅退还部分服务费。
- 责任限制：总责任上限为过去一个月服务费。
- 服务终止和数据迁移：终止后 30 天可导出部分数据，未说明提示词和日志导出。
- 监管配合：供应商“合理配合”，未明确时限和材料范围。

## 高风险或待谈判条款

- 客户数据可能用于模型改进，未排除客户内容。
- 删除机制没有明确完成期限和证明方式。
- 无实质审计权，分包商和境外处理边界不清。
- 责任上限过低，难覆盖数据泄露或侵权风险。

## 红旗风险条款

- “供应商可使用服务数据改进模型和服务质量”未区分客户内容、日志、匿名化数据和技术数据。

## 客户商务决策事项

- 是否接受在条款未修改前仅开放公开资料和低风险内部资料试点。
