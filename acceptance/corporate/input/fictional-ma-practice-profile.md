# 虚构并购 Practice Profile

> 律师审阅用草稿。本 profile 完全虚构。

- 交易立场：买方。
- 交易类型：少数股权投资。
- 目标公司行业：智能设备制造。
- 重大性阈值：单项金额超过人民币 100 万元，或可能影响交割、估值、持续经营、资质许可的事项。
- 红旗风险定义：未解除关联方担保、核心资质无法延续、重大诉讼仲裁、重大行政处罚、数据或安全事件无法解释。
- 交割条件口径：对投资安全、估值和控制权安排有重大影响的事项，优先列为交割前条件。
- 披露清单口径：任何偏离陈述保证、重大合同限制、关联交易、处罚、诉讼、资质问题均进入披露清单。
- 输出格式偏好：先给问题表，再给交割清单和披露清单。
