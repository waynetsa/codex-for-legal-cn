# Hearing Prep Result

> 律师审阅用草稿。不得直接对外发送、提交、签署或作为法律意见使用。

## 庭审目标

证明合同成立、卖方完成交付、买方尾款到期未付，并削弱买方质量异议抗辩。

## 法庭可能关注问题

- 质量异议是否在约定期限内提出。
- 签收人是否有权代表买方。
- 现有证据能否证明货物符合合同。

## 事实陈述要点

按签约、付款、生产、发货、签收、邮件确认、尾款到期、催款、质量异议、现场沟通顺序陈述。

## 证据出示顺序

合同 -> 付款流水 -> 发货单/签收单 -> 邮件确认 -> 对账单/发票 -> 催款函 -> 异议邮件 -> 会议纪要。

## 质证关注点

- 对方质量异议是否具体、及时。
- 对方是否有检测报告。
- 对方是否曾确认货物基本符合订单。

## 代理人发问提纲

- 买方何时首次发现质量问题。
- 买方为何在签收后较晚提出异议。
- 买方是否安排检测，检测材料何在。

## 对方可能发问

- 卖方是否承认质量瑕疵。
- 发货批次是否与合同一致。
- 会议纪要是否反映卖方整改承诺。

## 风险问题和庭后补充材料

质量异议期限、签收授权、检测证据缺口均需升级律师复核；庭后可能补充检测报告、原始邮件、签收授权、会议纪要签字版。

## 需客户确认事项

是否申请财产保全；是否接受调解或和解；是否能补充检测材料。
