# 虚构 IP Practice Profile

> 律师审阅用草稿。本材料完全虚构，仅用于 `cn-ip-legal` 验收。

## 虚构声明

本 profile 中的团队、客户、规则和角色均为虚构，不对应真实律所、真实客户或真实人员。

## 团队类型

知识产权与文化传媒法律服务团队。

## 客户类型

- 内容公司。
- 影视制作公司。
- 游戏公司。
- 品牌方。
- MCN。
- 平台。

## 常见事项

- 权属链条。
- 侵权初筛。
- 授权审查。
- 证据保全。
- 平台投诉。
- 律师函提纲。

## 风险偏好

- 对外发函、平台投诉、诉讼材料和证据保全采取谨慎策略。
- 权属链条存在关键缺口时，不建议直接对外主张。
- 商业化授权前必须补齐关键权利文件。

## 风险等级定义

- 低风险：事实清楚、权利文件完整、仅需格式调整。
- 中风险：存在待补文件或授权范围不清，但暂不影响核心路径。
- 高风险：可能影响维权基础、商业化授权或平台投诉结果。
- 红旗风险：关键权利缺口、证据灭失风险、对外发送前未复核、重大舆情或商业秘密风险。
- 待核验：法律依据、平台规则、权利基础或事实来源尚未确认。

## 必须升级事项

- 平台投诉、下架通知、律师函或沟通函拟对外发送。
- 关键权利文件缺失仍拟商业化或维权。
- 涉及独占、排他、转授权、改编权、境外渠道。
- 证据可能灭失，需要决定是否公证、时间戳、区块链存证或平台取证。
- 涉及重大金额、重要客户、重大舆情或商业秘密。

## 输出风格

- 优先表格化。
- 每个输出必须区分事实、风险、建议、待确认事项。
- 对法律依据、权利基础、平台规则统一写“待律师核验”。
- 不输出正式律师函或投诉文本，只输出内部提纲。

## 证据处理规则

- 记录来源、形成时间、保存方式、原件或原始载体情况。
- 三性提示必须写清真实性、合法性、关联性。
- 是否做公证、时间戳、区块链存证或平台取证，一律写“待律师判断”。

## 平台投诉处理规则

- 投诉材料不得由 AI 自动生成后直接提交。
- 投诉前必须核验权利基础、平台规则、证据完整性和商业影响。
- 反通知风险必须提示。

## 不得直接发送或提交的事项

- 律师函。
- 平台投诉。
- 下架通知。
- 诉讼或仲裁材料。
- 对客户或合作方的正式法律意见。

## 律师复核人角色

- 初审：虚构 IP 律师。
- 主办律师：虚构项目负责律师。
- 合伙人：虚构文化传媒业务合伙人。
- 客户确认人：虚构客户法务负责人。
