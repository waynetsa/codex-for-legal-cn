# Planned and Executed E2E Scenarios for CN IP Legal

> 律师审阅用草稿。本文件记录 `cn-ip-legal` MVP 的虚构验收路径。

## 已执行路径

本轮使用虚构“青岚纪内容 IP 争议包”完成以下路径：

1. `cold-start-interview`：生成 IP 团队画像和复核口径。
2. `rights-chain-review`：整理网络剧、角色形象、海报、音乐、游戏皮肤和品牌标识权属链条。
3. `infringement-triage`：对短视频账号、游戏皮肤和音乐片段使用做侵权初筛。
4. `ip-license-review`：审查虚构 IP 授权合同摘要。
5. `evidence-preservation-checklist`：整理 12 项证据的保全清单。
6. `takedown-and-demand-letter-outline`：生成平台投诉和维权函内部提纲。
