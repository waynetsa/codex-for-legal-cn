# Planned E2E Scenarios for CN IP Legal

> 律师审阅用草稿。本文件仅记录后续验收计划。

## 计划验收路径

1. `cold-start-interview`：生成 IP 团队 practice profile 草稿。
2. `rights-chain-review`：整理虚构内容项目权属链条。
3. `infringement-triage`：对虚构短视频/海报/音乐使用争议做初筛。
4. `ip-license-review`：审查虚构授权许可条款。
5. `evidence-preservation-checklist`：整理维权或应诉证据清单。
6. `takedown-and-demand-letter-outline`：生成平台投诉、下架通知或律师函内部提纲。

## 后续虚构材料建议

- 虚构短剧改编项目。
- 虚构游戏联名授权。
- 虚构短视频平台侵权争议。
- 虚构音乐和字体素材授权缺口。

## 验收最低标准

- 所有输出标注“律师审阅用草稿”。
- 不作最终权属或侵权结论。
- 法律依据、平台规则和证据判断均写“待律师核验”。
- 重大权利缺口、证据灭失、平台投诉和对外函件必须进入升级事项。
