# CN IP Legal End-to-End Acceptance

> 律师审阅用草稿。本目录仅使用明显虚构材料，不包含真实客户、真实案件、真实作品、真实合同、真实权利文件、真实证据、真实个人信息或商业秘密。

## 目的

本目录用于验证 `cn-ip-legal` MVP 的端到端使用路径。当前只做 acceptance，不修复 backlog，不发布新 tag。

## 验收路径

1. `cold-start-interview`
2. `rights-chain-review`
3. `infringement-triage`
4. `ip-license-review`
5. `evidence-preservation-checklist`
6. `takedown-and-demand-letter-outline`

## 文件索引

- 输入材料：`acceptance/ip/input/`
- 输出草稿：`acceptance/ip/output/`
- 评测记录：`acceptance/ip/eval/`
- 总结和 backlog：`acceptance/ip/summary/`

## IP MVP Acceptance 标准

- 能识别主要权利对象和权利类型。
- 能整理授权链条。
- 能识别权利缺口。
- 能做侵权初筛结构化输出，但不作最终侵权结论。
- 能整理证据保全清单。
- 能审查 IP 授权条款的核心风险。
- 能生成平台投诉或律师函内部提纲，但不得直接对外发送。
- 高风险和红旗风险必须进入升级事项。
- 法律依据必须标注“待律师核验”。
- 输出必须能被律师继续编辑。
- 不得出现真实客户资料。
- 不得生成正式法律意见。
