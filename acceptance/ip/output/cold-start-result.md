# Cold-start Result

> 律师审阅用草稿。本材料基于虚构验收样例生成。不构成法律意见。

## 团队画像摘要

虚构 IP 团队定位为知识产权与文化传媒法律服务团队，服务内容公司、影视制作公司、游戏公司、品牌方、MCN 和平台。

## 业务类型

- 版权、商标、商业秘密、不正当竞争。
- 影视、短剧、游戏、动漫、音乐、短视频、品牌联名。

## 客户类型

| 客户类型 | 常见事项 |
| --- | --- |
| 内容公司 | 权属链条、授权审查、维权准备 |
| 游戏公司 | 游戏化授权、素材权属、联名商业化 |
| 品牌方 | 联名授权、商标和宣传物使用 |
| MCN / 平台 | 投诉、反通知、内容下架 |

## 常见权利对象

- 网络剧、剧本、角色形象、海报、音乐片段、游戏皮肤、字体、品牌标识。

## 风险偏好

- 对外投诉、律师函和证据保全前采取谨慎策略。
- 权属缺口未补齐时，不建议直接对外主张或签署重大授权。

## 必须升级事项

- 关键权利文件缺失。
- 证据可能灭失。
- 平台投诉、下架通知、律师函拟发送。
- 排他授权、转授权、境外渠道、重大商业化。

## 输出格式偏好

- 表格化权属链条。
- 侵权初筛表。
- 授权审查备忘录。
- 证据保全清单。
- 下架/律师函内部提纲。

## 证据处理规则

- 记录证据来源、形成时间、保存方式、原件或原始载体。
- 公证、时间戳、区块链存证或平台取证均写“待律师判断”。

## 平台投诉处理规则

- 不得自动提交。
- 投诉材料须由虚构项目负责律师和虚构文化传媒业务合伙人复核。

## 律师复核节点

- 初稿生成后：虚构 IP 律师复核。
- 对外发送或提交前：虚构项目负责律师复核。
- 红旗风险：虚构文化传媒业务合伙人复核。
