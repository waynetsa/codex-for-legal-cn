# cn-privacy-legal Planned End-to-End Scenarios

> 律师审阅用草稿。本文件记录本轮虚构验收场景，不包含真实个人信息、真实隐私政策、真实 SDK 清单或真实数据处理协议。

## 场景一：消费类小程序数据合规体检

- 虚构产品：晴橙生活小程序。
- 虚构运营主体：晴橙互动科技有限公司。
- 目标：梳理个人信息处理活动、审阅隐私政策、识别第三方 SDK、营销推送、会员积分和用户权利响应风险。
- 覆盖 skills：`personal-info-processing-map`、`privacy-policy-review`、`privacy-impact-assessment`。

## 场景二：客服供应商数据处理协议审查

- 虚构供应商：北星客服助手。
- 目标：审查处理目的、范围、安全措施、分包、删除、审计权、安全事件通知和终止后处理。
- 覆盖 skill：`data-processing-agreement-review`。

## 场景三：境外远程运维初筛

- 虚构设定：境外技术团队可远程访问脱敏日志，但访问路径、权限边界和接收方材料不完整。
- 目标：识别数据类型、接收方所在地、远程访问、持续传输、告知同意和可能适用路径待核验。
- 覆盖 skill：`data-transfer-triage`。

## 场景四：用户删除和复制请求响应

- 虚构请求：用户要求注销账号并复制历史订单和客服沟通摘要。
- 目标：整理身份核验、受理渠道、内部部门、系统操作、留痕、限制响应情形和答复提纲。
- 覆盖 skill：`data-subject-request-workflow`。

## 本轮不做事项

- 不修复 acceptance backlog。
- 不发布 `v0.4.0-alpha`。
- 不接入真实 MCP 或真实系统。
- 不使用真实客户、真实用户、真实个人信息或真实供应商材料。
