## 风险、建议和待确认事项

| 类型 | 内容 |
| --- | --- |
| 事实 | 供应商可能远程访问脱敏日志和工单摘要，但接收方所在地、访问权限、频率、量级不明 |
| 风险 | 可能存在境外处理或跨境访问路径不清、告知同意不足、访问留痕不足 |
| 建议 | 暂停或限制访问；补充数据量级、接收方、权限矩阵、日志留痕、供应商安全材料 |
| 待确认事项 | 数据是否可重新去标识化、是否包含客服敏感描述、是否持续访问 |
| 待律师核验 | 可能适用路径、告知同意要求、评估或备案类义务 |

## 待补材料

- 接收方所在地和主体信息。
- 访问权限、频率、日志留痕。
- 数据字段和数据量级。
- 脱敏规则和可逆性说明。
- 供应商安全措施、分包和删除机制。

## 升级事项

- 红旗：境外远程访问事实存在但关键材料缺失。
- 需律师、数据合规负责人、IT / 安全负责人和管理层复核后方可继续使用。
