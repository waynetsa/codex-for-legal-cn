# Cold-start Result

> 律师审阅用草稿  
> 本材料基于虚构验收样例生成  
> 不构成法律意见

## 团队画像摘要

| 项目 | 内容 |
| --- | --- |
| 团队类型 | 个人信息保护、数据合规和产品合规联合团队 |
| 服务对象 | 企业法务、合规、产品、IT、安全、运营、客服、市场部门 |
| 适用语境 | 中国大陆法律语境；跨境事项待律师核验 |
| 输出定位 | 工作底稿、风险清单、台账和审阅意见 |

## 常见业务场景

- 会员注册、内容浏览、评论互动、订单或活动报名。
- 客服咨询、投诉处理、营销推送、个性化推荐。
- 第三方 SDK、供应商委托处理、境外远程运维。
- 用户删除、复制、更正、撤回同意、注销账号和投诉处理。

## 常见个人信息类型

| 类型 | 示例 | 风险提示 |
| --- | --- | --- |
| 联系方式 | 虚构手机号占位符 | 不得填写真实号码 |
| 账号信息 | 用户 ID、昵称、头像 | 评论区展示需核验告知 |
| 设备和日志 | 设备标识、登录日志、点击日志 | SDK 和远程运维需核验 |
| 位置信息 | 城市级位置、报名城市 | 敏感性待律师核验 |
| 订单和支付状态 | 虚构订单号、支付状态 | 不含真实账户 |
| 客服记录 | 工单摘要 | 可能含敏感描述 |
| 未成年人信息 | 可能存在未成年人用户 | 默认升级 |

## 常见处理活动

收集、存储、使用、加工、传输、提供、公开、删除、匿名化、去标识化。

## 第三方和供应商管理规则

- 要求供应商补充处理目的、数据类型、安全措施、分包、删除机制和安全事件通知。
- 第三方 SDK 必须列明名称、用途、数据类型、共享方式和退出路径。
- 分包、境外处理、远程访问或权限不透明时必须升级。

## 数据出境初筛规则

- 仅作初筛，不作确定出境合规结论。
- 接收方所在地、数据量级、传输方式、访问频率、告知同意状态均写“待律师核验”。
- 境外远程访问、持续传输、敏感个人信息或批量数据默认高风险。

## 用户请求响应规则

- 先识别请求类型和身份核验要求。
- 响应期限和限制响应情形统一写“待律师核验”。
- 模板化答复不得直接发送。

## 风险偏好

- 对第三方 SDK、境外处理、未成年人、敏感个人信息和用户请求答复采取审慎口径。
- 材料不足时只列“待补材料”和“待律师核验”，不形成确定结论。

## 必须升级事项

| 事项 | 升级对象 |
| --- | --- |
| 境外远程访问路径、权限和数据量级不明 | 主办律师、数据合规负责人、管理层 |
| 未成年人或敏感个人信息处理不清 | 主办律师、负责合伙人 |
| 隐私政策、用户答复、评估报告拟对外发布 | 主办律师、客户法务 |
| 安全事件、投诉、监管问询 | 负责合伙人、管理层 |

## 律师复核节点

- 输出初稿完成后。
- 对外发布或发送前。
- 形成管理层决策建议前。
- 涉及法律依据、监管口径和出境路径时。
