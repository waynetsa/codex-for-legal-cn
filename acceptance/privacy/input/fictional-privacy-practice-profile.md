# 虚构 Privacy Practice Profile

> 律师审阅用草稿。本材料为虚构验收样例，不含真实客户、真实企业、真实用户、真实个人信息、真实系统或真实供应商。

## 团队画像

- 团队类型：个人信息保护、数据合规和产品合规联合团队。
- 服务对象：企业法务、合规、产品、IT、安全、运营、客服、市场部门。
- 适用法域假设：中国大陆法律语境；跨境事项需单独核验。

## 常见业务场景

- 会员注册、内容分发、评论互动、订单履约、客服咨询、营销推送。
- 第三方 SDK 和供应商数据处理。
- 境外供应商远程访问或跨境支持。
- 用户查询、复制、更正、删除、撤回同意、注销账号和投诉处理。

## 常见个人信息类型

- 基本身份信息、联系方式、账号信息、设备信息、日志信息、位置信息、交易信息、行为数据、客服沟通记录、员工信息。

## 敏感个人信息判断提示

- 涉及未成年人、精确位置、证件、金融账户、健康、生物识别、行踪轨迹或可能影响重大权益的处理，默认列入升级事项并写“待律师核验”。

## 常见处理活动

- 收集、存储、使用、加工、传输、提供、公开、删除、匿名化、去标识化。

## 第三方和供应商管理规则

- 供应商必须提供处理目的、数据类型、安全措施、分包、删除机制、安全事件通知、审计或检查材料。
- 分包、再委托、境外处理或权限不透明时必须升级。

## 数据出境初筛规则

- 只做初筛，不作确定合规结论。
- 可能适用路径统一写“待律师核验”。
- 境外远程访问、持续传输、敏感个人信息或批量数据默认高风险。

## 用户请求响应规则

- 所有请求必须先识别类型和身份核验要求。
- 响应期限、拒绝或限制响应情形统一写“待律师核验”。
- 模板化答复不得直接发送，必须经律师或合规负责人复核。

## 风险等级定义

- 低风险：材料相对完整，未涉及敏感、未成年人、出境或重大共享。
- 中风险：存在告知、同意、共享、保存期限或供应商材料缺口。
- 高风险：涉及敏感个人信息、未成年人、境外处理、自动化决策或重大供应商缺口。
- 红旗风险：可能导致严重误用、监管风险、客户重大决策或资料泄露，需暂停自动处理并人工判断。
- 待核验：材料不足或法律依据不明。

## 必须升级事项

- 敏感个人信息、未成年人信息、境外处理、持续远程访问。
- 安全事件、投诉、监管问询或重大舆情。
- 隐私政策、用户答复或评估报告拟对外发布。
- 客户要求在材料不足时形成确定合规结论。

## 输出格式

- 台账优先使用短表。
- 风险、建议、待确认事项和升级事项分开列示。
- 所有输出标注“律师审阅用草稿”。

## 禁止事项

- 不得直接发布隐私政策、正式评估报告或监管提交材料。
- 不得把真实个人信息、客户资料或商业秘密输入未经批准的 AI 工具。
- 不得虚构法律依据、监管结论或主管机关口径。

## 律师复核人角色

- 主办律师。
- 数据合规负责人。
- 负责合伙人。
- 客户法务或合规负责人。
