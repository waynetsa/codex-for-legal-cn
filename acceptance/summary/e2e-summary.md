# E2E Alpha Acceptance Summary

> 本轮只使用虚构材料。所有输出均为律师审阅用草稿。

## 验收范围

本轮验收 `v0.1.0-alpha` 的三个核心插件：`cn-commercial-legal`、`cn-corporate-legal`、`cn-litigation-legal`。

## 三条路径是否跑通

| 路径 | 是否跑通 | 说明 |
| --- | --- | --- |
| 合同审查 | 是 | 完成 cold-start、合同审查、偏离清单、续约风险检查 |
| 并购尽调 | 是 | 完成 cold-start、资料室审阅、问题提取、交割清单、披露清单 |
| 诉讼案件 | 是 | 完成 intake、时间线、证据目录、争点表、庭前准备、案件周报 |

## 每个插件的通过项

- 商事合同：识别数据红旗、责任上限、自动续约、管辖偏离和电子签章核验点。
- 并购尽调：识别关联方担保、资质续期、重大合同限制、劳动社保、行政处罚和数据合规问题。
- 诉讼案件：识别质量异议期限、证据缺口、保全可能性和争点结构。

## 每个插件的主要问题

- 合同插件：替代表述可更接近可直接复制的谈判语言。
- 并购插件：重大性判断与交易文件影响的映射可更细。
- 诉讼插件：时间线可增加程序期限字段，并强化证据补强提示。

## 是否达到 alpha 可试用标准

达到。三条路径均可生成可编辑的律师审阅用草稿，红旗风险未漏报，未发现 P0 阻碍项。

## 下一步建议

先根据 `acceptance/summary/improvement-backlog.md` 开一个修复 PR，优化三个核心插件的模板和 skill 提示；不要直接进入第二阶段新插件开发。
