# cn-employment-legal Acceptance Plan

> 本目录用于规划 `cn-employment-legal` 后续端到端验收。本轮只补充 MVP 能力，不执行完整 acceptance。

## 当前状态

- `cn-employment-legal` 已进入 MVP 开发。
- 本轮新增劳动合同审查、员工手册审阅、解除风险初筛、竞业限制审查、外包派遣风险检查、内部调查计划和劳动争议证据包工作流。
- 所有输出均为“律师审阅用草稿”，不构成法律意见。
- 不使用真实客户、真实企业、真实员工信息、真实劳动合同、真实工资单、真实社保记录、真实内部调查材料或真实仲裁诉讼材料。

## 后续验收材料

后续 acceptance 应使用虚构员工解除争议和用工合规事实包，覆盖：

- 虚构企业用工背景。
- 虚构员工脱敏字段。
- 虚构劳动合同摘要。
- 虚构员工手册和制度摘要。
- 虚构解除、调岗或协商解除场景。
- 虚构竞业限制协议摘要。
- 虚构外包或派遣安排。
- 虚构内部调查线索。
- 虚构劳动争议证据材料。

## 最低验收标准

- 能识别用工主体、人员类型、合同类型和工作地点。
- 能识别员工手册的程序、内容和证据留存风险。
- 能对解除、终止、调岗降薪、待岗和裁员进行风险初筛。
- 能提示特殊保护情形、民主程序、公示送达、仲裁或诉讼期限均待律师核验。
- 能整理竞业限制、外包派遣、内部调查和劳动争议证据风险。
- 不生成正式法律意见、正式解除通知、正式员工手册、正式仲裁材料或正式调查结论。
- 高风险和红旗风险进入升级事项。
