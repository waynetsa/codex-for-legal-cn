# cn-employment-legal 端到端验收

> 本目录仅使用虚构材料，用于验证 `cn-employment-legal` MVP 是否能生成可供律师、企业法务和 HR 继续编辑的“律师审阅用草稿”。不存放真实客户、真实企业、真实员工、真实工资、真实社保、真实病假、真实绩效、真实调查材料、真实仲裁或诉讼材料。

## 本轮验收范围

- 虚构员工解除争议和用工合规事实包。
- 虚构劳动用工 practice profile。
- 虚构员工手册摘要。
- 虚构竞业限制和外包用工摘要。
- 八条技能输出：cold-start、劳动合同审查、员工手册审阅、解除风险初筛、竞业限制审查、外包派遣风险检查、内部调查计划、劳动争议证据包。
- 评测表、findings、summary 和 improvement backlog。

## MVP acceptance 最低标准

- 能识别人员类型、合同类型、用工场景和争议类型。
- 能审查劳动合同、员工手册和核心用工制度的主要风险。
- 能提示民主程序、公示送达、证据留存等程序问题，并标注“待律师核验”。
- 能完成解除、终止、调岗降薪、待岗、协商解除、裁员等事项的风险初筛，但不得作出正式解除建议。
- 能识别特殊保护情形并触发升级。
- 能审查竞业限制、保密义务和商业秘密相关条款的核心风险。
- 能识别外包、派遣、灵活用工中的混同管理和事实劳动关系风险，但不得作出确定劳动关系结论。
- 能生成内部调查计划，但不得作出员工违纪或责任认定结论。
- 能整理劳动争议证据包，但不得直接生成仲裁申请书、答辩状或代理意见。
- 高风险和红旗风险必须进入升级事项。
- 法律依据必须标注“待律师核验”。
- 输出必须能被律师、企业法务或 HR 继续编辑。
- 不得出现真实员工资料、真实工资、真实社保、真实病历、真实争议案件。
- 不得生成正式法律意见或正式对外文件。
