# 虚构劳动用工 Practice Profile

> 明确虚构声明：本文件仅用于端到端验收，不对应真实律所、真实企业或真实员工。

## 团队画像

- 团队类型：劳动用工、企业合规和争议解决联合团队。
- 服务对象：企业法务、HR、管理层、业务部门、律所劳动法团队。
- 默认法域：中国大陆，具体城市差异待律师核验。

## 常见用工场景

- 劳动合同、实习协议、劳务协议、顾问协议审查。
- 员工手册、考勤、绩效、奖惩、保密、反骚扰制度审阅。
- 解除、终止、调岗、降薪、待岗、协商解除、裁员风险初筛。
- 竞业限制和商业秘密保护。
- 外包、劳务派遣、灵活用工、平台用工。
- 内部调查和劳动争议材料整理。

## 常见人员类型

- 全职员工、实习生、劳务人员、派遣员工、外包人员、顾问、平台用工人员。
- 高管、核心技术人员、核心销售人员。
- 特殊保护人员提示：待律师核验。

## 风险等级定义

- 低风险：格式或轻微表述问题。
- 中风险：影响制度执行或争议处理，需要主办律师复核。
- 高风险：可能影响解除、证据、成本或管理层决策，必须升级。
- 红旗风险：可能导致严重误用、违法解除、群体争议、重大舆情、监管或刑事行政风险，必须暂停自动处理。
- 待核验：事实、证据或法律依据不足。

## 必须升级事项

- 解除、裁员、调岗降薪、待岗。
- 病假、医疗期、孕产哺乳、工伤、投诉举报等特殊情况。
- 群体性争议、重大金额或重大舆情。
- 竞业限制执行、商业秘密泄露、内部调查结论。
- 仲裁、诉讼、期限、保全、监管检查。

## 个人信息和证据处理规则

- 员工信息必须脱敏；真实材料只在私有环境处理。
- 证据目录必须标注来源、形成时间、证明目的、原件情况和三性提示。
- 民主程序、公示程序、期限、补偿或赔偿口径均写“待律师核验”。

## 输出格式

- 优先表格化、要点化。
- 每份输出开头标注“律师审阅用草稿”“不构成法律意见”。
- 不得生成正式解除通知、正式员工手册、正式仲裁材料或正式调查结论。

## 律师复核人角色

- 主办劳动法律师。
- 负责合伙人。
- 企业法务负责人。
- HR 负责人。
- 管理层决策人。
