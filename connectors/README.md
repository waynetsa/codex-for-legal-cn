# Connectors

本目录只提供 MCP 连接器占位文档和配置模板，不实现真实连接器，不连接真实律所系统，不包含真实 API 地址、账号、密钥、token 或 Cookie。

## MCP 连接器在本项目中的作用

- 插件负责法律工作流，例如合同审查、并购尽调、诉讼案件管理。
- 连接器负责在授权范围内读取或写入外部系统，例如文档管理、合同管理、案件管理、法研数据库、资料室或协作工具。
- 第一阶段仅提供占位说明，帮助律所规划私有部署。

## 部署审批

律所部署真实连接器前，必须由 IT、知识管理、风控或合规负责人审批，并确认客户授权、访问控制、审计日志、数据留存和供应商管理要求。

## 基本要求

- 最小权限。
- 只读优先。
- 按 matter、project、client 隔离。
- 不跨客户检索。
- 不默认写回。
- 所有写回动作必须人工确认。
- 真实配置不得提交到 GitHub。
- `.env`、本地密钥和私有配置必须被 `.gitignore` 排除。
