# Simulated Anonymized AI Privacy Pack

明确声明：本材料为模拟严格脱敏后的虚构合成材料，不来源于真实客户，不含真实企业、真实系统、真实个人信息或真实供应商材料。

## 场景概况

- 虚构企业：丙方内容科技有限公司
- 项目：内部 AI 办公助手与客服辅助工具上线
- 涉及部门：法务、市场、客服、IT / 安全、数据合规
- 工具用途：文档问答、客服辅助、营销内容生成、合同摘要
- 第三方供应商：虚构云端 AI SaaS 服务商
- 境外处理或远程访问：存在虚构设定，待律师核验

## 数据类型

| 类型 | 使用场景 |
| --- | --- |
| 公开资料 | 营销内容生成 |
| 客户资料 | 客服辅助和文档问答 |
| 合同资料 | 合同摘要 |
| 个人信息 | 客服记录、账号信息、行为日志 |
| 员工信息 | 内部知识库问答 |
| 行为日志 | 工具使用审计 |
| 商业秘密 | 内部项目文档 |

## 高风险问题

1. 客户资料可能被输入第三方 AI 工具。
2. 合同资料和客服记录可能包含个人信息。
3. 供应商是否使用客户输入训练模型未明确。
4. 境外远程访问和日志留存规则不清。

## 红旗风险

- 未完成供应商审查和数据处理边界确认前，不得上线处理客户资料或个人信息。

## 管理层决策事项

- 是否先限定公开资料和内部低敏材料试点。
- 是否要求私有化部署或禁用训练。

## 必须律师复核事项

- 个人信息影响评估、出境初筛、供应商合同和隐私政策均需律师复核。
