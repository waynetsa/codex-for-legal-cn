# v1.0.0 Post-Release QA

本目录用于 `v1.0.0` 发布后 QA。

本轮使用的是“模拟严格脱敏后的虚构合成材料”，不来源于真实客户底稿，不包含真实客户资料、真实案件材料、真实合同、真实个人信息、真实员工信息、真实监管材料或真实交易资料。

## 边界

- 不接真实 MCP。
- 不接真实律所系统、文档系统、合同系统、案件系统、法研数据库或监管数据库。
- 不提供法律意见。
- 所有输出均为“律师审阅用草稿”，基于虚构或模拟脱敏试点样例生成，不构成法律意见。

## QA 目标

- 判断项目能否进入真实律所受控脱敏试点。
- 检查跨插件组合使用是否保持安全边界。
- 如发现 P0/P1，后续应开修复 PR。
- 如未发现 P0/P1，项目开发可以暂告段落，等待真实脱敏试点反馈。
