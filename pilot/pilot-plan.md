# Pilot Plan

## 试点目标

用完全虚构材料模拟一次受控脱敏试点，检验 3 个高优先级插件是否能支持律师继续编辑、识别红旗风险并保持“律师审阅用草稿”的安全边界。

## 试点范围

本轮覆盖：

- `cn-commercial-legal`
- `cn-litigation-legal`
- `cn-ip-legal`

本轮不覆盖真实客户资料、真实合同、真实案件、真实证据、真实个人信息、真实 MCP 或生产系统。

## 选择理由

| 插件 | 选择理由 |
| --- | --- |
| cn-commercial-legal | 合同审查高频、低门槛，容易衡量节省时间和可编辑性。 |
| cn-litigation-legal | 材料整理价值高，适合检查证据、争点和时间线能力。 |
| cn-ip-legal | 与文化传媒、内容、版权、授权和侵权场景高度相关，适合验证权属链条和平台处置边界。 |

## 本轮不选择其他插件的原因

- 并购和监管对材料复杂度、事实核验和行业背景要求更高，更适合后续专项试点。
- AI governance、privacy、employment 可进入第二批试点。
- 本轮先验证高频、材料边界较清楚、反馈成本较低的 3 条路径。

## 成功标准

- 输出能被律师继续编辑。
- 红旗风险不漏报。
- 高风险进入升级事项。
- 没有正式法律意见口吻。
- 没有真实资料或敏感数据。
- 模拟律师平均可用性评分达到 4 分或以上。

## 停止条件

- 出现 P0 问题。
- 输出误导律师直接对外使用。
- 出现真实资料风险。
- 关键红旗风险漏报。

## 试点后下一步

根据 feedback 形成 v1 readiness 修复项，再决定是否进入真实脱敏试点。暂不发布 v1.0。
