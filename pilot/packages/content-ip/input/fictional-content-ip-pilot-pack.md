# Fictional Content IP Pilot Pack

明确声明：本材料完全虚构，仅用于受控试点模拟，不含真实作品、真实权利文件、真实平台数据或真实个人信息。

## 项目背景

- 虚构内容项目：动画短剧《云上机巧城》
- 权利对象：剧本、主角形象、宣传海报、主题音乐、15 秒短视频片段、游戏联动素材
- 客户角色：内容出品方

## 权利来源摘要

- 剧本由虚构编剧团队创作，存在委托创作合同。
- 主角形象由虚构设计工作室设计，授权合同载明“网络传播和宣传使用”，未明确游戏衍生品。
- 主题音乐来自虚构音乐人授权，授权期限为 2 年。
- 海报使用了第三方字体和背景素材，授权文件待补。

## 涉嫌使用行为

某虚构短视频账号发布与主角形象高度相似的营销短片，并在虚构电商小程序销售周边。

## 中高风险点

- 角色授权未明确游戏衍生品和周边开发。
- 海报字体和背景素材授权待补。
- 主题音乐授权期限可能影响后续传播。
