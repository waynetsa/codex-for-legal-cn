# Takedown and Demand Outline Draft

律师审阅用草稿  
本材料基于虚构试点样例生成  
不构成法律意见

## 内部提纲

| 模块 | 内容 |
| --- | --- |
| 权利基础 | 剧本、角色形象、音乐、海报相关权利文件，待律师核验 |
| 被投诉内容 | 虚构账号短视频和小程序周边商品 |
| 初步侵权事实 | 相似角色、商业使用、平台传播，均待律师核验 |
| 诉求选项 | 删除/下架、停止销售、删除宣传内容、保留协商空间 |
| 附件 | 权利证明、授权链条、截图、录屏、比对材料 |

## 不宜直接写入的内容

- “已经构成侵权”等确定结论。
- 未核验的损失金额。
- 未经客户确认的公开声明或媒体口径。

## 升级事项

- 投诉或发函前必须由律师复核权属链条、相似性、证据保全和客户商业目标。
