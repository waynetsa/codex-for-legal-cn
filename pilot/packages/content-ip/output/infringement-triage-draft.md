# Infringement Triage Draft

律师审阅用草稿  
本材料基于虚构试点样例生成  
不构成法律意见

## 初筛边界

本输出仅作侵权初筛，不作最终侵权结论。

| 维度 | 材料整理 | 初步风险 |
| --- | --- | --- |
| 权利基础 | 剧本、角色、音乐和海报权利文件部分完整 | 高，权属链条需补 |
| 使用行为 | 虚构账号发布相似短片并销售周边 | 中高，商业使用事实较明显 |
| 相似点 | 主角轮廓、配色、机关设定、宣传语接近 | 待律师核验 |
| 差异点 | 背景场景和音乐不同 | 需进一步比对 |
| 传播事实 | 短视频和小程序页面截图、录屏 | 需证据保全 |

## 下一步建议

| 动作 | 建议 |
| --- | --- |
| 立即保全 | 先保全页面、视频、商品、下单流程和传播数据。 |
| 平台下架 | 权属材料补齐后准备投诉。 |
| 发函 | 需律师复核权属、相似性和商业使用事实。 |
| 协商 | 可作为备选路径，需客户确认商业目标。 |

## 升级事项

- 权利链条缺口和商业使用持续传播并存，应升级合伙人和客户负责人。
