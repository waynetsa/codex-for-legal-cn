# Fictional Commercial Practice Profile

明确声明：本 profile 完全虚构，仅用于试点模拟。

## 团队口径

- 风险偏好：中低风险，优先保护回款、交付边界、知识产权和数据处理边界。
- 不可接受条款：无限责任、付款完全取决于主观满意、未经脱敏处理用户数据、甲方无成本任意解除。
- 可让步条款：合理验收期、合理保密期限、明确范围内的违约金。
- 必须升级事项：单方解除、数据处理、知识产权全部转让、责任限制例外过宽、自动续约。
- 输出风格：表格化、可编辑、区分事实、风险、建议、待确认事项和升级事项。
- 律师复核节点：形成对外修改意见前、客户商务让步前、签署前。
