# Controlled Fictional Pilot

本目录用于 `v0.6.0-alpha` 之后的受控脱敏试点模拟。

## 基本边界

- 本轮只使用完全虚构材料。
- 本轮不使用真实客户资料、真实案件材料、真实合同、真实个人信息、真实监管材料或真实交易资料。
- 本轮不接入真实 MCP、真实律所系统、文档系统、合同系统、案件系统、法研数据库或监管数据库。
- 本轮试点模拟不代表真实律师结论，只用于检验 workflow 可用性。
- 所有输出均为“律师审阅用草稿”，不构成法律意见，不得直接对外发送、提交、签署或发布。

## 试点目标

判断项目是否具备进入真实律所“受控脱敏试点”的条件，而不是判断是否可以直接发布 v1.0。

## 三个试点包

| 试点包 | 覆盖插件 | 业务场景 |
| --- | --- | --- |
| commercial-contract | cn-commercial-legal | 合同审查、偏离备忘、续约风险 |
| litigation-dispute | cn-litigation-legal | 诉讼案件 intake、时间线、证据、争点、状态 |
| content-ip | cn-ip-legal | 权属链条、侵权初筛、证据保全、平台投诉和律师函提纲 |

## 模拟评测角色

- 合伙人
- 主办律师 / 资深律师
- 初级律师

输出只用于评估 workflow 可用性、风险识别、可编辑性和试点边界。
