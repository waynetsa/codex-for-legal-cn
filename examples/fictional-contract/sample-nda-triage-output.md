# 虚构样例：云帆科技 NDA 初筛输出

> 律师审阅用草稿。本样例完全虚构。

| 项目 | 结论 | 说明 | 是否升级 |
|---|---|---|---|
| 分级 | 黄色 | 可轻量审查后推进 | 否 |
| 单向/双向 | 双向 | 双方均可能披露信息 | 否 |
| 保密范围 | 略宽 | 包含“所有商业信息”，建议增加合理例外 | 否 |
| 保密期限 | 待确认 | 保密义务持续五年，需确认业务可接受性 | 否 |
| 责任承担 | 中等 | 未见惩罚性违约金 | 否 |
| 夹带条款 | 有 | 包含简短非招揽条款，需确认是否符合授权 | 是 |

## 放行建议
修改保密范围例外和非招揽条款后，可由负责律师决定是否快速放行。法律依据待律师核验。
