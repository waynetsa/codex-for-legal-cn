# v0.6.0-alpha Overview

## 当前版本状态

`v0.6.0-alpha` 已完成 8 个插件从 scaffold / MVP / acceptance / alpha 修复到 alpha 可试用状态的闭环。当前 main 为 `4e75f1d`，Release 可访问。

## 当前可以解决的问题

- 为律师团队建立标准化 cold-start 访谈和 practice profile。
- 为 8 条常见法律服务线生成可编辑的律师审阅用草稿。
- 用虚构 acceptance 样例验证端到端输出结构。
- 用 P0/P1/P2 backlog 和 regression 记录修复闭环。
- 为后续脱敏试点提供模板、评测和安全边界基础。

## 当前不能解决的事情

- 不能提供正式法律意见。
- 不能替代律师事实核验、法律检索、案件判断或监管沟通。
- 不能处理真实客户资料或真实案件材料，除非未来在私有环境内另行设计。
- 不能连接真实 MCP、文档系统、合同系统、案件系统、监管数据库或法研数据库。
- 不能保证所有模板已经适合具体律所的内部审批和知识管理规范。

## v1.0 前必须补齐的能力

- 统一 8 个插件的 skill 口径、模板字段和输出长度。
- 增加私有试点指南、数据处理指南和样例脱敏指南。
- 明确公开仓库与私有部署边界。
- 为本地只读文件夹和本地模板库设计轻量集成示例。
- 形成试点评测表、反馈表和问题分级流程。
- 收敛关键 P1，给剩余 P2 制定处理计划。
