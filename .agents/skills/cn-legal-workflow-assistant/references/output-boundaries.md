# Output Boundaries

All outputs are lawyer-review drafts only.

## Required Header

Include this header in every substantive output:

```text
律师审阅用草稿
不构成法律意见
基于用户提供材料和本次 practice profile 生成
法律依据、事实、期限、金额、主体、证据和客户决策事项均需人工核验
不得直接对外发送、提交、签署或发布
```

## Required Sections

Use these sections unless the user asks for a narrower internal checklist:

- 事实摘要
- 风险识别
- 建议动作
- 待补材料
- 待确认事项
- 升级事项
- 律师复核清单

## Formal Document Boundary

For any of the following, produce only an internal draft or outline:

- court or arbitration materials
- regulator replies
- transaction documents
- employee notices or workplace investigation conclusions
- platform complaints or demand letters
- client-facing legal opinions
- public statements or announcements

Do not create a ready-to-submit, ready-to-send, ready-to-sign, or ready-to-publish version.

## Wording Rules

Prefer:

- 初步提示
- 待律师核验
- 基于现有材料
- 需补充事实
- 建议律师复核
- 需合伙人或负责人升级

Avoid:

- 必然违法
- 必然构成侵权
- 必然败诉
- 可以直接发送
- 可以直接提交
- 自动合规
- 无需律师复核
