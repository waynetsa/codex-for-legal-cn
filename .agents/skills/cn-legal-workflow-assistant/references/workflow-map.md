# Workflow Map

Use this file to route user-selected business workflows to repository plugin folders. Show business workflow names to users. Mention plugin names only if the user asks or when reading repository files internally.

## 1. 合同与交易文件

- plugin: `plugins/cn-commercial-legal`
- 适用：合同审查、NDA、偏离清单、续约解除、谈判语言
- 常用输出：合同审查备忘录、NDA 初筛表、偏离清单、续约解除风险清单

## 2. 公司与并购

- plugin: `plugins/cn-corporate-legal`
- 适用：并购尽调、资料室、问题提取、交割清单、披露清单
- 常用输出：尽调表、问题清单、交割清单、披露清单

## 3. 诉讼与争议解决

- plugin: `plugins/cn-litigation-legal`
- 适用：案件 intake、事实时间线、证据目录、争点表、庭前准备、案件周报
- 常用输出：案件 intake 表、时间线、证据目录、争点表、案件周报

## 4. 知识产权与内容传媒

- plugin: `plugins/cn-ip-legal`
- 适用：权属链条、侵权初筛、授权审查、证据保全、平台投诉/函件提纲
- 常用输出：权属链条表、侵权初筛表、授权审查备忘录、证据保全清单、投诉/函件提纲

## 5. AI 治理

- plugin: `plugins/cn-ai-governance-legal`
- 适用：AI 使用制度、工具准入、风险评估、供应商合同、治理差距
- 常用输出：AI 使用制度草稿、工具准入表、风险评估表、供应商合同审查、治理差距清单

## 6. 隐私与数据合规

- plugin: `plugins/cn-privacy-legal`
- 适用：个人信息处理地图、隐私政策审阅、数据处理协议、影响评估、数据出境初筛、用户请求响应
- 常用输出：处理活动地图、隐私政策审阅意见、DPA 审查、影响评估初稿、出境初筛表、用户请求响应流程

## 7. 劳动用工

- plugin: `plugins/cn-employment-legal`
- 适用：劳动合同、员工手册、解除风险、竞业限制、外包派遣、内部调查、劳动争议证据包
- 常用输出：合同审查、员工手册审阅、解除风险初筛、竞业限制审查、外包派遣风险清单、调查计划、证据包

## 8. 监管合规

- plugin: `plugins/cn-regulatory-legal`
- 适用：监管动态影响、合规义务清单、问询响应、处罚风险初筛、整改计划、管理层简报
- 常用输出：监管影响简报、合规义务清单、问询响应提纲、处罚风险初筛、整改计划、管理层简报
