# Litigation Legal Evals

本目录用于保存诉讼与争议解决插件的虚构或充分脱敏评测样本。不得提交真实案件、案号、证据原文、当事人或诉讼策略。

## 样本准备

- 使用虚构买卖合同纠纷、服务合同纠纷或股权争议。
- 保留事实顺序、证据关系和争点结构，替换全部主体和可识别信息。
- 准备参考时间线、证据目录、争点表和期限提示。

## 推荐评测 skill

- `matter-intake`
- `chronology-builder`
- `evidence-index`
- `issue-chart`
- `hearing-prep`
- `matter-status`

## 最低可接受标准

- 关键期限不得遗漏。
- 证据三性提示必须标为待律师核验。
- 不得虚构法院观点或证据事实。
- 周报必须区分进展、风险、计划和客户决策事项。

## 常见失败类型

- 把客户陈述写成已证实事实。
- 遗漏诉讼时效、保全或上诉期限。
- 证明目的过度扩张。
- 争点表未区分事实争点和法律争点。

## 反馈方式

评测结果应反馈到对应 `SKILL.md`、案件模板、证据目录模板和 practice profile 的期限管理规则。
