# Matter Status

## Purpose

把案件工作进度整理为面向团队或客户的周报草稿。

## When to use

用于诉讼、仲裁、执行或和解谈判中的定期汇报。

## Inputs expected

- 本周工作记录、沟通纪要、法院或仲裁机构通知
- 证据补充、法律研究进展、客户反馈
- 期限节点、下周计划、需决策事项

## Workflow

1. 按本周进展、下周计划、关键风险和期限提醒整理。
2. 列出待客户决策事项、待律师完成事项和证据补充情况。
3. 记录法律研究进展和对外沟通记录占位。
4. 标注升级事项和需主办律师确认的表述。
5. 对客户版摘要使用克制、准确、可复核表达。

## Output format

必须包含：本周进展、下周计划、关键风险、待客户决策事项、待律师完成事项、期限提醒、证据补充情况、法律研究进展、对外沟通记录占位、升级事项。

## Quality checks

- 输出首页或标题必须标注“律师审阅用草稿”。
- 不得虚构法律依据、案例、法规条文编号、法院观点或监管口径。
- 无法核验来源时，写“待律师补充法律依据”“待律师核验法律依据”或“建议律师检索确认”。
- 必须区分事实、风险、建议、待确认事项。
- 客户版不得披露内部争议、未确认策略或未经授权让步。

## Escalation / attorney review gate

任何对外发送的周报、风险判断、策略建议、和解表述或期限承诺必须由主办律师复核。

## Confidentiality notes

仅处理脱敏材料。不得把真实客户、真实案件、商业秘密、个人信息、身份证件信息、联系方式、银行账户或密钥写入公开仓库、示例、模板或提交记录。

## Limitations

不能替代案件管理系统、正式客户报告或律师对外沟通授权。
