# Matter Status

## Purpose

生成案件周报草稿，帮助团队同步进展、风险、下周计划和客户待确认事项。

## When to use

用于诉讼或争议解决项目的内部周报、客户状态更新草稿和团队例会准备。

## Inputs expected

- 脱敏案件进展。
- 本周完成事项、下周计划、关键期限。
- 风险变化和待客户确认事项。

## Workflow

1. 汇总本周进展。
2. 更新关键期限和事项状态。
3. 标注风险变化和待确认事项。
4. 输出周报草稿。

## Output format

“律师审阅用草稿”：本周进展、关键风险、下周计划、待确认事项、律师复核点。

## Quality checks

- 不披露不应向客户发送的内部策略。
- 不确认未核实进展。
- 关键日期必须标注来源或假设。

## Escalation / attorney review gate

任何对客户发送的周报必须由负责律师复核。

## Confidentiality notes

不得公开真实案件名称、客户、案号、证据或策略。

## Limitations

不替代正式客户沟通、案件管理系统或律师判断。
