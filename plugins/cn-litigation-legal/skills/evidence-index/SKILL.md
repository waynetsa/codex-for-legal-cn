# Evidence Index

## Purpose

把脱敏证据材料整理成可供律师复核和庭审准备使用的证据目录草稿。

## When to use

用于起诉、应诉、仲裁、庭前会议、证据交换和内部证据复盘。

## Inputs expected

- 脱敏证据清单、证据摘要或文件名
- 证据来源、形成时间、提交主体
- 诉请/抗辩目标、争点表或时间线

## Workflow

1. 为每项证据编号并记录名称、来源、形成时间和提交主体。
2. 写明证明目的和对应争点。
3. 提示真实性、合法性、关联性需要律师核验的点。
4. 记录原件情况、缺页缺章、来源链条和待补强事项。
5. 按争点或时间顺序整理输出。

## Output format

表格字段必须包含：证据编号、证据名称、来源、形成时间、提交主体、证明目的、真实性提示、合法性提示、关联性提示、原件情况、待补强事项、对应争点。

## Quality checks


本技能必须遵守 `shared/guardrails/` 与 `shared/templates/escalation-matrix.md`：

- 所有输出必须标注“律师审阅用草稿”。
- 不得将 AI 输出直接对外发送、提交、签署或作为法律意见使用。
- 必须人工核验法律依据、事实来源、客户材料和引用来源；无来源时写“待律师核验”。
- 真实客户资料、案件材料、合同、证据、交易文件、个人信息和密钥不得提交到公开仓库。
- 输出必须区分事实、风险、建议、待确认事项和升级事项。


- 输出首页或标题必须标注“律师审阅用草稿”。
- 不得虚构法律依据、案例、法规条文编号、法院观点或监管口径。
- 无法核验来源时，写“待律师补充法律依据”“待律师核验法律依据”或“建议律师检索确认”。
- 必须区分事实、风险、建议、待确认事项。
- 不得写“证据有效”这类最终判断，只能提示核验点。
