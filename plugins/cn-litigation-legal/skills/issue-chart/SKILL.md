# Issue Chart

## Purpose

整理案件争点、相关事实、证据、对方可能观点和待补强事项。

## When to use

用于诉讼策略讨论、庭前准备、代理词或答辩状结构设计。

## Inputs expected

- 脱敏事实时间线。
- 证据目录。
- 请求、抗辩方向和程序阶段。

## Workflow

1. 提取争议焦点。
2. 关联支持事实和证据。
3. 标注对方可能反驳和材料缺口。
4. 生成争点表。

## Output format

“律师审阅用草稿”：争点、我方事实、证据、对方可能观点、风险、待确认事项。

## Quality checks

- 不虚构法院观点。
- 法律依据不足时写“待律师补充法律依据”。
- 区分事实争点和法律争点。

## Escalation / attorney review gate

诉讼策略、法律定性、举证责任和庭审表达必须由律师确认。

## Confidentiality notes

争点表可能包含诉讼策略，不得公开真实版本。

## Limitations

不替代律师的案件判断、诉讼策略和法律论证。
