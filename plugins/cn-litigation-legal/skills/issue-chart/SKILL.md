# Issue Chart

## Purpose

把案件事实和证据转化为律师可复核的争点分析表。

## When to use

用于案件策略会、庭前准备、代理意见框架、答辩思路和客户汇报。

## Inputs expected

- 事实时间线、证据目录、客户目标
- 对方主张或可能抗辩
- 已知法律问题、法院或仲裁阶段

## Workflow

1. 识别核心争点和次级争点。
2. 分别列明我方主张、对方可能主张、相关事实和现有证据。
3. 标注证明难点、待研究法律问题和可能的法庭关注点。
4. 提出应对策略草稿和是否升级。
5. 法律问题统一写“建议律师检索确认”或“待律师核验法律依据”。

## Output format

表格字段必须包含：争点、我方主张、对方可能主张、相关事实、现有证据、证明难点、待研究法律问题、可能的法庭关注点、应对策略、是否升级。

## Quality checks


本技能必须遵守 `shared/guardrails/` 与 `shared/templates/escalation-matrix.md`：

- 所有输出必须标注“律师审阅用草稿”。
- 不得将 AI 输出直接对外发送、提交、签署或作为法律意见使用。
- 必须人工核验法律依据、事实来源、客户材料和引用来源；无来源时写“待律师核验”。
- 真实客户资料、案件材料、合同、证据、交易文件、个人信息和密钥不得提交到公开仓库。
- 输出必须区分事实、风险、建议、待确认事项和升级事项。


- 输出首页或标题必须标注“律师审阅用草稿”。
- 不得虚构法律依据、案例、法规条文编号、法院观点或监管口径。
- 无法核验来源时，写“待律师补充法律依据”“待律师核验法律依据”或“建议律师检索确认”。
- 必须区分事实、风险、建议、待确认事项。
- 不能虚构对方主张，应标明“可能主张”。
