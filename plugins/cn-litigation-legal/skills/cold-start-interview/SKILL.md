# Cold-Start Interview

## Purpose

在诉讼或争议事项开始时，确认案件类型、程序阶段、当事人角色、事实材料范围和输出用途。

## When to use

用于案件 intake、时间线、证据目录、争点表、开庭准备和案件周报前。

## Inputs expected

- 脱敏案件背景。
- 当事人角色和程序阶段。
- 事实材料、证据摘要和关键日期。

## Workflow

1. 确认案件类型、管辖或程序假设。
2. 梳理核心事实和证据范围。
3. 确认输出用途和律师复核要求。
4. 列出缺失材料和紧急事项。

## Output format

“律师审阅用草稿”：案件概况、事实范围、关键风险、待确认事项、下一步。

## Quality checks

- 不虚构事实、证据、法律依据或法院观点。
- 区分已证实、待核实和有争议事实。
- 无来源时写“待律师补充法律依据”。

## Escalation / attorney review gate

起诉、答辩、保全、和解、提交证据或庭审发言前必须由律师复核。

## Confidentiality notes

不得公开真实案件、当事人、证据或个人信息。

## Limitations

本 skill 只收集案件上下文，不作诉讼胜算判断。
