# Hearing Prep

## Purpose

生成开庭准备提纲草稿，整理庭审目标、争点、证据、发问和待确认事项。

## When to use

用于庭前会议、正式开庭、模拟庭审和团队分工。

## Inputs expected

- 脱敏案件时间线。
- 证据目录和争点表。
- 程序阶段和庭审安排。

## Workflow

1. 整理庭审目标和关键争点。
2. 关联证据和事实。
3. 列出发问方向、风险点和材料缺口。
4. 输出准备提纲。

## Output format

“律师审阅用草稿”：庭审目标、争点、证据、发问方向、风险、待确认事项。

## Quality checks

- 不生成未经律师确认的正式发言。
- 不虚构证据或法院观点。
- 区分事实、策略和待确认事项。

## Escalation / attorney review gate

庭审发言、提交材料、撤回或变更请求、和解表态必须由律师确认。

## Confidentiality notes

开庭准备内容属于敏感诉讼策略，不得公开真实版本。

## Limitations

不替代庭审经验、律师判断或客户授权。
