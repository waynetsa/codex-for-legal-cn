# Hearing Prep

## Purpose

生成庭审目标、法庭关注问题、事实陈述、举证质证和发问准备的工作底稿。

## When to use

用于开庭、仲裁庭审、庭前会议、证据交换前的团队准备。

## Inputs expected

- 事实时间线、证据目录、争点表
- 庭审阶段、法庭或仲裁庭已关注问题
- 客户确认事项、证人或经办人信息的脱敏摘要

## Workflow

1. 明确庭审目标和需证明的核心事实。
2. 列出法庭可能关注问题和我方回应要点。
3. 安排证据出示顺序和质证关注点。
4. 准备代理人发问提纲、对方可能发问和风险问题。
5. 列出庭后补充材料和需客户确认事项。

## Output format

必须包含：庭审目标、法庭可能关注问题、事实陈述要点、证据出示顺序、质证关注点、代理人发问提纲、对方可能发问、风险问题、庭后补充材料、需客户确认事项。

## Quality checks


本技能必须遵守 `shared/guardrails/` 与 `shared/templates/escalation-matrix.md`：

- 所有输出必须标注“律师审阅用草稿”。
- 不得将 AI 输出直接对外发送、提交、签署或作为法律意见使用。
- 必须人工核验法律依据、事实来源、客户材料和引用来源；无来源时写“待律师核验”。
- 真实客户资料、案件材料、合同、证据、交易文件、个人信息和密钥不得提交到公开仓库。
- 输出必须区分事实、风险、建议、待确认事项和升级事项。


- 输出首页或标题必须标注“律师审阅用草稿”。
- 不得虚构法律依据、案例、法规条文编号、法院观点或监管口径。
- 无法核验来源时，写“待律师补充法律依据”“待律师核验法律依据”或“建议律师检索确认”。
- 必须区分事实、风险、建议、待确认事项。
- 不得生成可直接提交法院或仲裁庭的最终代理意见。
