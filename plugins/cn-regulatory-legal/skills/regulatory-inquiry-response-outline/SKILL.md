# Regulatory Inquiry Response Outline

## Purpose

生成监管问询或检查通知响应内部提纲，帮助律师、法务、合规和业务部门梳理来函要求、事实材料、待补材料、内部分工、回复口径风险、正式提交前禁止项和管理层决策事项。

## When to use

- 收到监管问询、监管函、检查通知、整改通知、处罚告知前置沟通或类似材料时。
- 需要组织事实核验、材料清单和内部责任分工，但尚未形成正式监管回复时。

## Inputs expected

- 来函或通知的脱敏摘要。
- 要求回复事项、截止时间、涉及业务、已有事实、现有材料。
- 内部责任部门、审批规则、管理层关注事项和是否涉及对外披露。

## Workflow

1. 标注“律师审阅用草稿”，说明不得直接提交监管机关。
2. 梳理监管事项摘要、来函类型、要求回复事项和截止时间，截止时间写“待律师核验”。
3. 区分客户已有事实、待补事实、待提交材料清单和内部分工。
4. 单独列出回复口径风险、不宜直接回复事项、正式提交前禁止项、审批链和律师复核清单。
5. 对事实未核验、材料不完整、内部口径不一致、承诺过度、可能涉及处罚或整改、对外披露影响等事项设置高风险或红旗风险。
6. 列出管理层决策事项和升级事项。

## Output format

- 监管事项摘要。
- 来函或通知类型。
- 要求回复事项。
- 截止时间：待律师核验。
- 客户已有事实。
- 待补事实。
- 待提交材料清单。
- 内部分工。
- 回复口径风险。
- 不宜直接回复事项。
- 正式提交前禁止项。
- 正式提交前审批链。
- 律师复核清单。
- 管理层决策事项。
- 升级事项。

## Quality checks

- 是否避免直接生成正式监管回复文本。
- 是否区分事实、材料、风险、建议和待确认事项。
- 是否没有虚构监管机关口径、处罚结论或执法趋势。
- 是否将截止时间和法律依据标注为“待律师核验”。
- 是否清楚写明未经律师、合规负责人和管理层复核不得提交。

## Escalation / attorney review gate

涉及行政处罚、现场检查、重大整改、对外公告、媒体舆情、业务暂停、正式提交或董事会决策时，必须升级给负责律师、合伙人和管理层。

## Confidentiality notes

不得输入真实监管函、真实处罚材料、真实内部调查材料、客户经营数据、个人信息或商业秘密。真实材料应脱敏或在私有环境处理。

## Limitations

本技能只生成内部提纲和材料清单，不生成正式监管回复，不判断违法构成、处罚风险或监管结论。
