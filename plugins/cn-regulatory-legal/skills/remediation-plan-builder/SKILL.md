# Remediation Plan Builder

## Purpose

生成合规整改计划草稿，帮助律师、法务、合规负责人和业务部门将问题事项、根因、整改目标、责任部门、交付物、截止时间、验收标准和留痕材料结构化。

## When to use

- 完成合规自查、监管问询响应、行政处罚风险初筛或专项整改方案设计时。
- 需要把整改建议拆分为短期止血、中期制度修复、长期治理建设时。

## Inputs expected

- 问题事项、风险等级、根因初步分析、现有材料和管理层关注点。
- 责任部门、责任人角色、可用资源、时间要求和验收方式。

## Workflow

1. 标注“律师审阅用草稿”，说明不得直接作为正式整改报告提交。
2. 梳理问题事项、风险等级和根因初步分析。
3. 将整改措施拆分为短期止血、中期制度修复、长期治理建设。
4. 为每项措施列明责任部门、责任人角色、交付物、截止时间、验收标准和留痕材料。
5. 列出管理层决策事项、待律师核验依据和升级事项。

## Output format

- 问题事项。
- 风险等级。
- 根因初步分析。
- 整改目标。
- 短期止血措施。
- 中期制度修复措施。
- 长期治理建设措施。
- 责任部门。
- 责任人角色，不写真人姓名。
- 整改措施。
- 交付物。
- 截止时间。
- 验收标准。
- 留痕材料。
- 管理层决策事项。
- 待律师核验依据。
- 升级事项。

## Quality checks

- 是否避免写成正式整改报告或监管提交材料。
- 是否拆分短期、中期、长期措施。
- 是否每项措施都有责任部门、交付物、验收标准和留痕材料。
- 是否避免真实姓名和真实内部整改材料。

## Escalation / attorney review gate

涉及监管提交、重大预算、业务停改、人员问责、董事会决策、行政处罚或舆情风险时，必须升级给律师、合伙人和管理层。

## Confidentiality notes

不得输入真实整改报告、内部调查材料、员工信息、客户经营数据、个人信息或商业秘密。真实材料应脱敏或在私有环境处理。

## Limitations

本技能不确认整改充分性，不替代律师判断，不生成正式整改报告或监管提交材料。
