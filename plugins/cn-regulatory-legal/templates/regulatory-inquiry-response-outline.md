# 监管问询响应内部提纲模板

> 律师审阅用草稿。不构成法律意见，不得直接作为正式监管回复、正式整改报告或正式对外公告提交。所有事实、期限、法律依据和回复口径均为待律师核验。

## 3. 不宜直接回复事项

| 事项 | 不宜直接回复原因 | 建议处理方式 | 是否升级 |
| --- | --- | --- | --- |
| 事实未核验、材料不完整、内部口径不一致、承诺过度、可能涉及处罚或整改、可能影响对外披露 | 待律师判断 | 先补事实、统一口径、完成审批链 | 是 |

## 4. 正式提交前禁止项

| 禁止项 | 检查状态 | 责任角色 |

| 未经事实负责人确认关键事实 |  | 业务负责人 |
| 未经管理层批准作出重大整改承诺 |  | 管理层 |
| 使用未经核验的法规、口径或期限 |  | 经办律师 |
