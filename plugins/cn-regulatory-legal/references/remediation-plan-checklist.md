# 合规整改计划检查清单

> 律师审阅用草稿；不得直接作为正式整改报告或监管提交材料。

## 整改结构

- 问题事项。
- 风险等级。
- 根因初步分析。
- 整改目标。
- 责任部门。
- 责任人角色，不能写真人姓名。
- 交付物。
- 截止时间。
- 验收标准。
- 留痕材料。

## 三阶段整改

- 短期止血：暂停高风险动作、补充审批、保留证据、限制影响扩大。
- 中期制度修复：制度修订、流程调整、培训和台账补齐。
- 长期治理建设：组织责任、系统控制、审计机制和定期复盘。

## 升级触发

- 涉及正式监管提交、重大预算、业务停改、人员问责、董事会决策、行政处罚或舆情风险。
## Alpha 修复补充：整改跟踪字段

> 律师审阅用草稿。以下仅为整改计划编制提醒，不构成正式整改报告或监管承诺；法律依据、整改期限和监管口径均为待律师核验。

整改计划除问题、责任部门、交付物和验收标准外，应补充：

| 字段 | 检查重点 |
| --- | --- |
| 依赖条件 | 是否需要系统改造、预算、供应商配合、管理层授权或跨部门资源 |
| 复核频率 | 是否明确周度、双周、月度或节点复核安排 |
| 逾期升级 | 逾期后是否升级至合规负责人、业务负责人、管理层或合伙人 |
| 管理层复盘 | 是否需要定期查看重大整改进度、资源缺口和对外口径 |
| 留痕材料 | 是否保存会议纪要、审批记录、整改交付物、验收记录和培训记录 |

红旗触发：无负责人、无期限、无验收标准、无留痕材料、整改承诺超出能力、可能影响监管回复或对外披露口径。
