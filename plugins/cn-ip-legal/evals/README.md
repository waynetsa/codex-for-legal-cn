# CN IP Legal Evals

> 律师审阅用草稿。本目录用于评测 `cn-ip-legal` MVP，不保存真实客户、真实案件、真实权利文件或真实证据。

## 推荐评测 skills

- `rights-chain-review`
- `infringement-triage`
- `ip-license-review`
- `evidence-preservation-checklist`
- `takedown-and-demand-letter-outline`

## 评测维度

- 权属链条完整性。
- 授权范围、期限、地域、渠道、转授权、改编和商业化识别。
- 侵权初筛是否区分相似点、差异点、权利基础和证据缺口。
- 证据目录是否包含证明目的、三性提示、原件/原始载体和待补强事项。
- 下架/函件提纲是否明确不得直接发送。
- 高风险和红旗风险是否触发律师或合伙人复核。

## 最低标准

- 所有输出标注“律师审阅用草稿”。
- 不作最终权属、侵权或责任结论。
- 法律依据和平台规则均标注“待律师核验”。
- 不出现真实客户、真实案件、真实权利文件、真实证据或个人信息。
