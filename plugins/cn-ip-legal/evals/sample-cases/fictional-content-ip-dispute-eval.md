# Fictional Content IP Dispute Eval

> 律师审阅用草稿。本样例完全虚构，仅用于评测 `cn-ip-legal` MVP。

## 虚构背景

“星灯影业”计划将虚构网络小说《雾城回声》改编为短剧，并与“蓝橙互动”合作开发同名小游戏。上线前，团队发现某短视频账号使用了相似角色海报和片段混剪，同时小游戏美术素材中有部分字体和背景音乐来源不明。

## 评测覆盖

- 权属链条：小说改编权、剧本、角色形象、海报、音乐、字体、游戏美术。
- 授权范围：短剧、小游戏、衍生品、宣传渠道、地域、期限、转授权和改编。
- 侵权初筛：短视频账号海报和片段使用的相似点、差异点、证据缺口。
- 证据整理：网页链接、截图、录屏、发布时间、账号信息、源文件、授权合同。
- 平台投诉或律师函提纲：权利基础摘要、涉嫌侵权行为、主要请求、待补材料。

## 预期输出

- 不作最终侵权结论。
- 所有法律依据写“待律师核验”。
- 重大权属缺口、平台投诉和证据灭失风险进入升级事项。
