# 中国 IP 工作流检查清单

> 律师审阅用草稿。以下为流程提醒，不构成法律意见。法律依据均待律师核验。

## 权属链条

- 明确权利对象和权利类型。
- 核验创作、委托、职务作品、转让、授权或继承等来源文件。
- 检查授权范围、期限、地域、渠道、转授权、改编和商业化。
- 标记权利缺口和待补文件。

## 授权许可

- 授权标的是否清楚。
- 独占、排他或普通许可是否明确。
- 收益分配、保底、分成、结算和审计是否可执行。
- 权利瑕疵担保、第三方索赔和侵权责任承担是否清楚。
- 解除、终止、到期后处理是否完整。

## 侵权初筛

- 被主张权利是否有基础文件。
- 涉嫌使用行为、渠道、时间和范围是否可证明。
- 相似点和差异点是否分别列明。
- 是否存在授权、合理使用、权利用尽、独立创作或其他抗辩方向，均待律师核验。

## 证据保全

- 网页、短视频、直播、应用商店、游戏页面、销售页面、聊天记录是否及时保存。
- 是否需要公证、时间戳、区块链存证或平台取证，待律师判断。
- 是否存在证据灭失、链接失效、账号删除或内容替换风险。

## 升级事项

- 重大权属缺口。
- 独占/排他授权冲突。
- 高价值项目或重大商业化使用。
- 需发送律师函、平台投诉、诉讼或仲裁材料。
- 商业秘密、行政或刑事风险、重大舆情风险。

## Alpha fix: 红旗触发标准

以下事项应直接进入升级事项：

- 关键权利文件缺失但拟发起投诉、发函或商业授权。
- 授权主体、原始权利人、授权方或被授权方不一致。
- 授权期限已过或地域、渠道、媒介、用途不清。
- 转授权缺少书面依据或审批机制。
- 证据可能灭失、网页仍在线且可能删除、账号可能注销。
- 平台规则或法律依据尚未核验但拟对外提交材料。
