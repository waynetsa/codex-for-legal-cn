# Infringement Triage

## Purpose

对涉嫌侵权或被投诉事项进行初筛，整理权利基础、使用行为、相似点、差异点、证据缺口、抗辩方向和下一步建议。输出为“律师审阅用草稿”，不得写成最终侵权结论。

## When to use

- 版权侵权初筛。
- 商标近似或混淆风险初筛。
- 角色形象、海报、片段、短视频、音乐、游戏素材争议。
- 平台投诉前初筛。
- 被投诉后的应对初筛。

## Inputs expected

- 被主张权利材料和权利人身份说明。
- 涉嫌使用内容、使用渠道、时间、范围和商业化情况。
- 对比材料、截图、链接、下载记录、沟通记录。
- 我方目标：维权、下架、谈判、应诉、反通知或内部风险判断。

## Workflow

1. 明确本技能不作最终侵权结论。
2. 整理被主张权利和涉嫌使用行为。
3. 对比相似点和差异点，区分事实、风险和待确认事项。
4. 标注权利基础、权利有效性、授权范围、使用范围和证据来源为“待律师核验”。
5. 初步分级：低 / 中 / 高 / 红旗 / 待核验。
6. 列出证据缺口、可能抗辩方向和下一步建议。
7. 判断是否需要立即证据保全或合伙人升级。

## Quality checks

- 是否标注“律师审阅用草稿”。
- 是否区分事实、风险、建议、待确认事项。
- 是否写明法律依据、权利基础、证据来源均“待律师核验”。
- 是否避免直接作出最终侵权、权属或责任结论。
- 是否将高风险、红旗风险、期限紧迫或证据灭失风险列入升级事项。

## Escalation / attorney review gate

以下事项必须由执业律师、主办律师或合伙人复核：对外发送函件、平台投诉、诉讼或仲裁提交、证据保全申请、权属链条重大缺口、独占/排他授权、重大金额、跨境授权、商业秘密、可能涉及行政或刑事风险、重大舆情风险。AI 输出不得直接作为法律意见、律师函、投诉材料或客户决策依据。

## Confidentiality notes

真实权利文件、合同、底稿、证据、平台后台截图、未公开内容素材、客户名称、个人信息和商业秘密必须在私有环境处理并脱敏。公开仓库只保存模板、流程和虚构样例，不得提交密钥、token、Cookie 或私有系统配置。

## Limitations

本技能不提供法律意见，不确认权属、侵权、混淆、损害赔偿、平台规则适用或诉讼胜率。涉及法律依据、案例、法规、法院观点和平台规则时，应写“待律师核验”。
