# Cold-start Interview

## Purpose

生成 `cn-ip-legal` 的团队 practice profile 草稿，帮助律师团队明确常见事项、风险口径、输出格式和复核规则。所有结果均为“律师审阅用草稿”。

## When to use

- 第一次为某个团队启用本插件时。
- 团队业务范围、客户类型、风险偏好或复核规则发生变化时。
- 准备把律所内部 playbook 写入私有 profile 前。

## Inputs expected

- 团队名称和负责角色。
- 客户类型和常见事项：知识产权权属链条、版权侵权初筛、商标/著作权/商业秘密争议材料整理、IP 授权条款审查、开源合规初筛。
- 适用法域和跨境假设。
- 风险等级偏好、必须升级事项、禁止事项。
- 常用输出格式和模板偏好。

## Workflow

1. 先确认本插件目前仅为 scaffold，不代表 alpha 可试用。
2. 逐项访谈团队：
1. 团队主要处理交易 IP 尽调、授权合同、侵权争议、商业秘密还是开源合规？
2. 常见权利类型包括商标、著作权、专利、软件、数据、商业秘密中的哪些？
3. 权属链条缺失、授权范围不明、侵权风险或开源许可证冲突的升级规则是什么？
4. 哪些材料不得放入公开仓库或公开 AI 工具？
3. 将访谈结果整理为 `practice-profile.md` 草稿。
4. 标出需要负责律师确认的内容。
5. 记录版本号、更新日期和复核人角色。

## Output format

- 标题：`中国知识产权法律工作流 practice profile 草稿`。
- 基本信息。
- 常见事项和材料类型。
- 风险等级偏好。
- 必须升级事项。
- 输出格式偏好。
- 禁止事项。
- 律师复核规则。
- 版本记录。

## Quality checks

- 是否标注“律师审阅用草稿”。
- 是否区分事实、风险、建议、待确认事项。
- 是否避免虚构法律依据、监管口径、案例或第三方模板。
- 是否明确本插件仍处 scaffold 阶段。

## Escalation / attorney review gate

任何对外发送、提交、签署、出具法律意见或客户依赖的内容，必须由执业律师或负责合伙人复核。涉及高风险、红旗风险、跨境、监管调查、重大交易或争议事项时，应暂停自动处理并升级。

## Confidentiality notes

不得把真实客户资料、案件材料、交易文件、个人信息、商业秘密、密钥或私有配置提交到公开仓库。真实 profile 应保存在私有环境，公开仓库仅保留模板、流程和虚构样例。

## Limitations

本技能只生成团队访谈和 profile 草稿，不提供法律意见，不替代律师判断，不确认具体法律依据。法律依据、监管规则和事实来源均需写“待律师核验”。
