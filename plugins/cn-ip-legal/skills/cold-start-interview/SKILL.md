# Cold-start Interview

## Purpose

访谈知识产权、文化传媒和娱乐法律团队，生成团队专用 `practice-profile.md` 草稿，用于后续权属链条、侵权初筛、授权审查、证据整理和下架/函件提纲工作流。所有输出均为“律师审阅用草稿”。

## When to use

- 第一次启用 `cn-ip-legal` 时。
- 团队新增影视、综艺、短剧、游戏、动漫、音乐、短视频、广告、出版或品牌授权业务时。
- 团队需要把常用 playbook、风险口径、证据处理规则写入私有 profile 时。

## Inputs expected

- 团队名称、负责律师角色、复核层级。
- 主要业务类型：版权、商标、商业秘密、不正当竞争、娱乐传媒、游戏、广告、出版、音乐、短视频等。
- 客户类型：内容公司、影视公司、游戏公司、艺人经纪、品牌方、MCN、平台、制造企业等。
- 常见项目：授权审查、侵权维权、平台投诉、诉前函、证据整理、权属链条核查。
- 常用证据类型、常用模板、风险偏好和禁止事项。

## Workflow

1. 说明本项目不提供法律意见，输出仅为律师审阅用草稿。
2. 访谈团队业务范围：
   - 主要处理哪些权利类型：著作权、商标、商业秘密、反不正当竞争、肖像/姓名/声音相关权益、域名或平台账号等。
   - 是否重点服务影视、综艺、短剧、游戏、动漫、文学、音乐、短视频、直播、广告或品牌联名。
3. 访谈客户和项目：
   - 客户常见身份：权利人、被投诉方、授权方、被授权方、平台、制作方、发行方、品牌方。
   - 常见项目：权属链条核查、授权条款审查、侵权初筛、证据保全、平台投诉、律师函、诉前准备。
4. 访谈风险口径：
   - 哪些权利缺口、独占授权、转授权、改编权、平台投诉、证据灭失、舆情或商业秘密事项必须升级。
   - 哪些内容只能写“待律师核验”。
5. 访谈输出偏好：
   - 表格、备忘录、证据目录、权属链条图、函件提纲、客户摘要。
6. 生成 `practice-profile.md` 建议结构，并列出待负责律师确认的问题。

## Output format

- `practice-profile.md` 建议结构。
- 访谈问答摘要。
- 团队风险等级定义。
- 必须升级事项。
- 常用证据和模板清单。
- 律师复核节点。
- 版本记录。

## Quality checks

- 是否标注“律师审阅用草稿”。
- 是否区分事实、风险、建议、待确认事项。
- 是否写明法律依据、权利基础、证据来源均“待律师核验”。
- 是否避免直接作出最终侵权、权属或责任结论。
- 是否将高风险、红旗风险、期限紧迫或证据灭失风险列入升级事项。

## Escalation / attorney review gate

以下事项必须由执业律师、主办律师或合伙人复核：对外发送函件、平台投诉、诉讼或仲裁提交、证据保全申请、权属链条重大缺口、独占/排他授权、重大金额、跨境授权、商业秘密、可能涉及行政或刑事风险、重大舆情风险。AI 输出不得直接作为法律意见、律师函、投诉材料或客户决策依据。

## Confidentiality notes

真实权利文件、合同、底稿、证据、平台后台截图、未公开内容素材、客户名称、个人信息和商业秘密必须在私有环境处理并脱敏。公开仓库只保存模板、流程和虚构样例，不得提交密钥、token、Cookie 或私有系统配置。

## Limitations

本技能不提供法律意见，不确认权属、侵权、混淆、损害赔偿、平台规则适用或诉讼胜率。涉及法律依据、案例、法规、法院观点和平台规则时，应写“待律师核验”。
