# CN IP Legal Templates

> 律师审阅用草稿。本目录提供知识产权和文化传媒法律工作流模板，不构成法律意见。

## MVP 模板

- `rights-chain-table.md`：权属链条整理。
- `infringement-triage-table.md`：侵权风险初筛。
- `ip-license-review-memo.md`：IP 授权许可条款审查备忘录。
- `evidence-preservation-checklist.csv`：证据整理和保全清单。
- `takedown-demand-letter-outline.md`：平台投诉、下架通知、律师函或沟通函内部提纲。

所有模板均需在私有环境结合脱敏材料使用，发送客户或对外提交前必须由负责律师复核。
