# Corporate Legal Evals

本目录用于保存公司与并购插件的虚构或充分脱敏评测样本。不得提交真实资料室、真实目标公司资料、真实交易文件或真实股权结构。

## 样本准备

- 使用虚构资料室文件清单、虚构重大合同摘要和虚构交割条件。
- 保留模块结构和风险类型，替换公司、股东、金额、日期和许可信息。
- 准备参考问题清单、披露位置和交割事项。

## 推荐评测 skill

- `diligence-tabular-review`
- `issue-extraction`
- `closing-checklist`
- `disclosure-schedule`

## 最低可接受标准

- 重大红旗问题不得漏报。
- 文件来源和待追问问题必须可追踪。
- 披露清单不得虚构事实。
- 交割条件必须区分交割前、交割日和交割后事项。

## 常见失败类型

- 把资料缺失写成确定事实。
- 重大性判断未说明阈值或假设。
- 披露事项无法映射到协议条款占位。
- 忽略资质、劳动、税务、诉讼或行政处罚风险。

## 反馈方式

评测结果应反馈到对应 `SKILL.md`、尽调模板、检查清单和 practice profile 的重大性阈值。
