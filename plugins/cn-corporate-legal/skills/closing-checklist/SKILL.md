# Closing Checklist

## Purpose

生成公司与并购项目交割清单草稿，帮助项目团队跟踪先决条件、交割文件和责任人。

## When to use

用于签约后交割准备、交割前条件核对和项目管理。

## Inputs expected

- 脱敏交易结构和交易文件摘要。
- 交割条件、文件清单和时间表。
- 责任人和审批要求。

## Workflow

1. 整理先决条件。
2. 列出交割文件和签署主体。
3. 标注状态、责任人和截止日期。
4. 标记需律师确认的条件。

## Output format

“律师审阅用草稿”：事项、文件、责任方、状态、截止日期、风险、待确认事项。

## Quality checks

- 不新增交易文件未载明的义务。
- 关键日期和状态必须标注来源或假设。
- 缺失信息进入待确认清单。

## Escalation / attorney review gate

交割条件豁免、文件签署、资金流转和监管审批事项必须由律师确认。

## Confidentiality notes

不得公开真实交易时间表、签署安排或交割资金信息。

## Limitations

不替代项目管理系统、签署核验或正式交割法律意见。
