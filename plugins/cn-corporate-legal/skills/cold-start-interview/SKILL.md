# Cold-Start Interview

## Purpose

在公司与并购项目开始时，确认交易类型、项目阶段、资料范围、法域假设和输出要求。

## When to use

用于尽调、披露清单、交割清单、重大合同清单和初步风险筛查前。

## Inputs expected

- 脱敏项目背景。
- 交易结构、客户角色和时间表。
- 资料室索引或文件摘要。

## Workflow

1. 确认项目目标和交易阶段。
2. 明确资料范围、缺失资料和优先级。
3. 确定风险等级、输出格式和复核人。
4. 形成初始问题清单。

## Output format

“律师审阅用草稿”：项目背景、资料范围、优先事项、待确认问题、下一步。

## Quality checks

- 区分事实、风险、建议和待确认事项。
- 不虚构公司信息或法律依据。
- 不替代资料室完整性核查。

## Escalation / attorney review gate

交易结构、重大风险、披露口径和交割条件必须由项目律师确认。

## Confidentiality notes

不得公开真实交易、估值、股权结构或资料室文件。

## Limitations

本 skill 只建立项目上下文，不作最终尽调结论。
