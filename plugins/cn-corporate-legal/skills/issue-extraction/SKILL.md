# Issue Extraction

## Purpose

把资料室审阅结果转化为可写入尽调报告、披露清单或交易文件的结构化问题台账。

## When to use

用于并购、投资、重组项目的法律尽调问题识别和内部复核。

## Inputs expected

- 脱敏文件摘要、访谈纪要或尽调表
- 项目 playbook、重大性阈值、交易结构
- 已知客户关注点、披露要求和交割目标

## Workflow

1. 按股权结构、出资、公司治理、重大合同、资质许可、知识产权、劳动用工、税务、诉讼仲裁、行政处罚、数据合规、关联交易、债务、担保、环保安全、不动产和租赁、国资或外资审批提示、反垄断申报提示、交易限制或优先权提示分类。
2. 为每个问题写明事实摘要和来源占位。
3. 说明风险、重大性、对交易文件的影响和建议追问。
4. 提出可能的交割条件、交割后义务或披露位置。
5. 标注待律师核验法律依据和是否升级。

## Output format

表格字段必须包含：问题编号、问题领域、事实摘要、风险说明、重大性判断、对交易文件的影响、建议追问、建议交割条件或交割后义务、待律师核验法律依据、是否升级。

## Quality checks

- 输出首页或标题必须标注“律师审阅用草稿”。
- 不得虚构法律依据、案例、法规条文编号、法院观点或监管口径。
- 无法核验来源时，写“待律师补充法律依据”“待律师核验法律依据”或“建议律师检索确认”。
- 必须区分事实、风险、建议、待确认事项。
- 不把未核验资料写成确定事实，应使用“根据已提供材料初步显示”。

## Escalation / attorney review gate

红旗风险、可能影响成交、估值、陈述保证、赔偿、交割条件、监管审批或客户披露义务的事项必须升级。

## Confidentiality notes

仅处理脱敏材料。不得把真实客户、真实案件、商业秘密、个人信息、身份证件信息、联系方式、银行账户或密钥写入公开仓库、示例、模板或提交记录。

## Limitations

不能替代专项法律检索、监管沟通、税务审计、财务审计或商业判断。
