# Issue Extraction

## Purpose

从脱敏公司资料、合同摘要和项目记录中提取重大法律问题。

## When to use

用于尽调报告、内部问题清单、管理层访谈准备和交易风险汇总。

## Inputs expected

- 脱敏资料摘要。
- 业务模块或资料室目录。
- 重大性阈值和项目风险口径。

## Workflow

1. 识别事实来源。
2. 按公司治理、股权、合同、资质、争议、行政处罚、税务、劳动等模块归类。
3. 标注重大性和待补资料。
4. 生成问题摘要。

## Output format

“律师审阅用草稿”：模块、事实、风险、建议、待确认事项、可能披露位置。

## Quality checks

- 不把未经核实的材料写成确定事实。
- 重大性判断必须说明假设。
- 无来源时写“待律师补充法律依据”。

## Escalation / attorney review gate

可能影响交易结构、估值、交割条件或披露义务的问题必须升级律师。

## Confidentiality notes

不得公开真实公司名称、股东、估值或交易文件。

## Limitations

不替代项目律师对重大性和交易影响的判断。
