# Diligence Tabular Review

## Purpose

把资料室文件清单、文件摘要或脱敏文件内容整理成可追踪的尽调审阅表。

## When to use

用于资料室第一轮扫读、文件索引、问题台账准备、尽调报告工作底稿。

## Inputs expected

- 脱敏资料室文件清单或文件摘要
- 资料室目录结构和文件编号
- 项目 practice profile、重大性阈值
- 需要重点关注的主体、期间、交易模块

## Workflow

1. 按资料室目录识别文件类型和涉及主体。
2. 提取文件日期、摘要、关键条款或关键事实。
3. 标注风险点、重大性、待追问问题和建议披露位置。
4. 保留引用来源占位，便于律师回查原文件。
5. 对不确定事项写“待律师核验事项”。

## Output format

表格字段必须包含：文件名称、文件类型、涉及主体、文件日期、摘要、关键条款或关键事实、风险点、重大性、待追问问题、建议披露位置、引用来源占位、待律师核验事项。

## Quality checks


本技能必须遵守 `shared/guardrails/` 与 `shared/templates/escalation-matrix.md`：

- 所有输出必须标注“律师审阅用草稿”。
- 不得将 AI 输出直接对外发送、提交、签署或作为法律意见使用。
- 必须人工核验法律依据、事实来源、客户材料和引用来源；无来源时写“待律师核验”。
- 真实客户资料、案件材料、合同、证据、交易文件、个人信息和密钥不得提交到公开仓库。
- 输出必须区分事实、风险、建议、待确认事项和升级事项。


- 输出首页或标题必须标注“律师审阅用草稿”。
- 不得虚构法律依据、案例、法规条文编号、法院观点或监管口径。
- 无法核验来源时，写“待律师补充法律依据”“待律师核验法律依据”或“建议律师检索确认”。
- 必须区分事实、风险、建议、待确认事项。
- 不得把文件名推测为事实结论，摘要必须标注来源占位。
