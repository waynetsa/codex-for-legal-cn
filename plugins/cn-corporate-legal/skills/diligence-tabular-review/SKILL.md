# Diligence Tabular Review

## Purpose

基于脱敏资料室索引或文件摘要，生成尽调问题台账。

## When to use

用于公司与并购项目法律尽调初筛和资料室审阅。

## Inputs expected

- 脱敏资料室清单。
- 文件摘要、版本和上传状态。
- 客户角色、交易阶段和关注事项。

## Workflow

1. 按模块分类资料。
2. 识别缺失资料、异常事项和需追问问题。
3. 标注风险等级和负责复核人。
4. 生成问题台账。

## Output format

“律师审阅用草稿”表格：编号、模块、事实、风险、建议、待确认事项、负责人。

## Quality checks

- 问题必须来源于已提供材料或明确缺失项。
- 不推断未披露交易事实。
- 法律依据不足时写“待律师补充法律依据”。

## Escalation / attorney review gate

重大合同、资质许可、诉讼仲裁、行政处罚、税务和劳动风险事项必须升级。

## Confidentiality notes

资料室内容不得进入公开仓库；样例必须虚构或脱敏。

## Limitations

不替代完整法律尽调或专项法律意见。
