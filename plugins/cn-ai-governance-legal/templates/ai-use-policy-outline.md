## 4. 禁止使用场景和禁止输入内容

| 禁止输入内容 | 示例 | 例外审批 |
| --- | --- | --- |
| 客户秘密 | 客户名单、客户沟通、客户合同 | 需律师、法务、合规审批 |
| 案件材料 | 证据、诉讼策略、代理意见 | 原则禁止公开工具 |
| 未公开交易资料 | 尽调资料、交易结构、报价 | 需私有环境和审批 |
| 商业秘密 | 产品路线图、未公开价格 | 需管理层和法务审批 |
| 个人信息 | 客户联系人、员工资料 | 需数据合规审批 |
| 员工敏感信息 | 绩效、处分、健康相关信息 | 原则禁止公开工具 |
| 源代码 | 内部代码、接口文档 | 需安全和研发负责人审批 |
| 财务数据 | 成本、预算、预测 | 需财务和管理层审批 |
| 账号密码或密钥 | token、API key、Cookie | 禁止输入 |
| 未经授权第三方作品 | 图片、音乐、代码、文本 | 需权利核验 |
