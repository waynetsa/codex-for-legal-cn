# AI 供应商审查清单

> 律师审阅用草稿。不构成采购批准或法律意见。

## 基本信息

- 供应商名称：
- 服务名称：
- 服务类型：SaaS / API / 私有化 / 嵌入式功能 / 其他。
- 部署区域：
- 数据处理角色和边界：

## 数据条款

- 客户数据是否用于训练：待确认。
- 训练、微调、日志分析和产品改进是否区分。
- 数据保留期限和删除机制。
- 数据导出和迁移机制。
- 是否涉及分包或第三方处理。
- 是否涉及跨境或境外处理提示。

## 安全和审计

- 安全措施说明。
- 访问控制。
- 加密和隔离。
- 日志和审计权。
- 安全事件通知。
- 漏洞和应急响应。

## 输出和知识产权

- 输出内容权属。
- 第三方侵权责任。
- 开源或训练数据来源提示。
- 对外使用限制。

## 商务和责任

- SLA 和服务可用性。
- 责任限制。
- 赔偿范围。
- 解除和终止。
- 终止后的数据删除和迁移。
- 监管配合。

## 升级触发

- 供应商要求使用客户数据训练。
- 删除机制不清。
- 审计权缺失。
- 分包不可控。
- 跨境或境外处理未说明。
- 责任限制明显异常。
- 输出权属和侵权责任不清。

## 输出监控和事故响应

- 是否有输出抽检机制。
- 是否有高风险输出拦截机制。
- 是否记录提示词、输入类型、输出用途和复核人角色。
- 是否有安全事件、错误输出、数据泄露、侵权投诉或客户投诉的响应流程。
- 是否有暂停服务、撤回输出、通知客户、通知监管或供应商配合机制。
- 是否有定期复盘和模型/工具退役机制。

所有法律依据和监管口径：待律师核验。
