# cn-employment-legal Templates

本目录存放劳动用工 MVP 模板。模板只用于生成“律师审阅用草稿”，不得作为正式法律意见、正式员工手册、正式解除通知、正式仲裁材料或正式调查结论直接使用。

## 模板清单

- `employment-contract-review-memo.md`：劳动合同、实习协议、劳务协议、顾问协议审查备忘录。
- `employee-handbook-review-memo.md`：员工手册和规章制度审阅备忘录。
- `termination-risk-triage-table.md`：解除、终止、调岗降薪、待岗、裁员风险初筛表。
- `non-compete-review-memo.md`：竞业限制和保密义务审查备忘录。
- `outsourcing-dispatch-risk-checklist.md`：外包、劳务派遣、灵活用工、平台用工风险清单。
- `workplace-investigation-plan.md`：内部调查计划草稿。
- `labor-dispute-evidence-pack.md`：劳动仲裁或诉讼前证据包草稿。

## 使用规则

- 使用前先读取团队 practice profile。
- 真实员工信息必须脱敏或仅在私有环境处理。
- 法律依据、地方规则、仲裁或法院观点统一写“待律师核验”。
- 高风险和红旗风险必须进入升级事项。
