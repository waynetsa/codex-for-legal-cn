# Employment Contract Review

## Purpose

生成劳动合同及相关用工协议的审查意见草稿，帮助律师识别用工主体、人员类型、合同期限、试用期、薪酬、社保、保密、竞业、知识产权、解除终止和争议解决风险。输出必须标注“律师审阅用草稿”。

## When to use

- 审查劳动合同、实习协议、劳务协议、顾问协议、聘用协议或类似文件时。
- 企业准备更新标准用工文本时。
- 律师需要先形成条款风险表和客户决策事项时。

## Inputs expected

- 协议文本或摘要。
- 我方角色：企业、员工、顾问或其他。
- 人员类型、岗位、工作地点、合同期限、薪酬结构和特殊安排。
- 团队 practice profile、客户风险偏好和必须升级事项。

## Workflow

1. 标注输出为律师审阅用草稿，并说明不构成法律意见。
2. 识别合同基本信息、用工主体、人员类型和合同类型。
3. 按工作岗位、地点、期限、试用期、工作时间、休息休假、薪酬、社保公积金、保密、竞业、知识产权、培训服务期、解除终止、违约责任、争议解决逐项审查。
4. 区分事实、风险、建议、客户决策事项和待律师核验依据。
5. 对高风险和红旗风险写入合伙人升级事项。
6. 输出可由律师继续编辑的表格和简明摘要。

## Output format

- 文件信息。
- 用工主体和人员类型判断。
- 合同类型判断。
- 关键条款摘要。
- 风险等级总览。
- 逐条审查意见表：条款位置、条款主题、风险等级、问题说明、对我方影响、建议修改方向、建议替代表述、待律师核验依据、是否升级。
- 客户决策事项。
- 合伙人升级事项。
- 可给客户看的简明摘要草稿。

## Quality checks

- 是否覆盖合同基本信息、工作岗位、工作地点、期限、试用期、工作时间、薪酬、社保公积金、解除终止和争议解决。
- 是否对竞业、保密、知识产权、培训服务期和违约责任单独判断。
- 是否把地方规则、法条依据、仲裁或法院观点写成“待律师核验”。
- 是否避免直接生成正式合同修改稿。
- 是否把高风险和红旗风险写入升级事项。

## Escalation / attorney review gate

涉及特殊保护人员、解除终止、竞业限制、服务期违约金、重大薪酬调整、跨城市用工、群体性合同调整或重大争议风险时，必须升级给主办律师或负责合伙人。不得直接对外发送审查意见或正式合同文本。

## Confidentiality notes

处理真实合同时，应删除或替换员工姓名、身份证件、联系方式、薪酬、银行账户、社保、公积金、绩效、病假、孕产、工伤等信息。公开仓库不得存放真实劳动合同或真实员工材料。

## Limitations

本技能不确认劳动关系、解除合法性、竞业有效性、补偿金额或具体争议结果。所有法律依据和地方规则需写“待律师核验”。
