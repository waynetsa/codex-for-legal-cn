# Cold-start Interview

## Purpose

访谈律师、企业法务、HR 或合规负责人，生成 `cn-employment-legal` 专用 practice profile 草稿。输出只作为“律师审阅用草稿”，不提供法律意见，不替代负责律师对具体城市政策、案件事实和证据规则的判断。

## When to use

- 首次启用劳动用工插件时。
- 企业客户、行业、用工地点、人员类型或风险偏好发生变化时。
- 需要把合伙人审查口径、HR 协作规则、民主程序和证据处理规则写入团队 profile 时。

## Inputs expected

- 服务对象：企业客户、HR、法务、管理层、业务部门、律所劳动法团队。
- 员工类型：全职员工、实习生、劳务人员、派遣员工、外包人员、顾问、平台用工人员。
- 常见事项：劳动合同、员工手册、解除终止、裁员、调岗降薪、竞业限制、保密、外包派遣、内部调查、劳动仲裁。
- 用工地点和法域假设：默认中国大陆，具体城市差异待律师核验。
- 风险偏好、必须升级事项、证据处理规则、员工个人信息处理规则、常用输出格式和律师复核节点。

## Workflow

1. 说明本插件只生成律师审阅用草稿，不生成正式法律意见。
2. 访谈服务对象、常见用工场景、人员类型、争议类型和业务节奏。
3. 访谈团队对解除、裁员、调岗降薪、竞业、内部调查、特殊保护人员、工伤或医疗期等事项的升级规则。
4. 访谈民主程序、公示送达、证据留存、员工个人信息保护、内部调查保密和反报复规则。
5. 访谈输出偏好：表格、备忘录、风险清单、证据包、管理层摘要。
6. 生成 `practice-profile.md` 草稿，并列出需要负责律师确认的口径。
7. 写入版本记录，说明后续技能应先读取该 profile 再输出。

## Output format

- 标题：劳动用工 practice profile 草稿。
- 团队信息和服务对象。
- 常见用工场景、人员类型和争议类型。
- 风险等级定义。
- 必须升级事项。
- 证据处理规则。
- 民主程序和公示程序提示。
- 员工个人信息处理规则。
- 常用输出格式。
- 禁止事项。
- 律师复核人角色。
- 版本记录。

## Quality checks

- 是否标注“律师审阅用草稿”。
- 是否区分事实、风险、建议、待确认事项。
- 是否把法律依据、地方口径、仲裁或法院观点写成“待律师核验”。
- 是否覆盖服务对象、人员类型、用工地点、证据规则、升级规则和禁止事项。
- 是否避免真实员工信息、工资、社保、绩效、投诉举报或内部调查材料。

## Escalation / attorney review gate

涉及解除、裁员、调岗降薪、待岗、特殊保护人员、工伤、医疗期、孕产期、竞业限制、群体性争议、监管调查、重大舆情、内部调查结论或仲裁诉讼材料的事项，必须由劳动法律师或负责合伙人复核。任何对外发送、提交、签署或依赖的内容均不得直接使用 AI 输出。

## Confidentiality notes

不得把真实客户资料、真实员工姓名、身份证件、手机号、工资、社保、公积金、绩效、病假、孕产、工伤、投诉举报、内部调查或仲裁诉讼材料提交到公开仓库。真实 profile 应保存在私有环境，本仓库只保留模板、流程和虚构样例。

## Limitations

本技能只生成访谈和 profile 草稿，不确认解除合法性、劳动关系、竞业有效性、违纪责任或赔偿金额。涉及法律依据、地方规则、仲裁和法院观点时，统一写“待律师核验”。
