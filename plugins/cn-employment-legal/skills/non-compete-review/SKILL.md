# Non-compete Review

## Purpose

生成竞业限制和保密义务审查意见草稿，帮助律师识别适用人员、岗位信息接触情况、竞业范围、期限、地域、补偿、违约责任、商业秘密范围、离职交接和证据留存风险。

## When to use

- 审查劳动合同、保密协议、竞业限制协议或离职协议中的竞业条款时。
- 企业拟对核心员工设置或执行竞业限制时。
- 员工离职后需要评估竞业、保密和证据留存安排时。

## Inputs expected

- 协议文本或条款摘要。
- 员工岗位、职责、接触信息、离职安排和补偿安排。
- 拟限制的行业、地域、期限、竞争企业范围和违约责任。

## Workflow

1. 标注“律师审阅用草稿”，说明不得作出当然有效或当然无效结论。
2. 识别适用人员、岗位、信息接触情况和商业秘密范围。
3. 审查竞业范围、期限、地域、补偿安排、违约责任、保密义务、离职交接和证据留存。
4. 将可执行性风险、法律依据和地方口径写为待律师核验。
5. 输出建议修改方向、客户决策事项和升级事项。

## Output format

- 适用人员和岗位信息。
- 接触信息和商业秘密范围。
- 竞业条款审查表。
- 补偿和违约责任风险表。
- 保密义务和离职交接提示。
- 证据留存清单。
- 可执行性风险提示：待律师核验。
- 风险等级。
- 建议修改方向。
- 客户决策事项。
- 升级事项。

## Quality checks

- 是否覆盖竞业范围、期限、地域、补偿、违约责任和保密义务。
- 是否避免确定性有效或无效结论。
- 是否明确商业秘密范围和证据留存缺口。
- 是否将法律依据和地方裁判口径写成待律师核验。

## Escalation / attorney review gate

涉及高管、核心技术人员、核心销售人员、大额违约责任、离职后争议、竞业执行、商业秘密泄露或诉讼仲裁准备时，必须升级给劳动法律师或负责合伙人。

## Confidentiality notes

不得提交真实员工身份、岗位秘密、客户名单、技术资料、薪酬、离职沟通或商业秘密材料。公开样例必须虚构。

## Limitations

本技能不确认竞业条款当然有效、当然无效或一定可执行，不替代律师对岗位、补偿、地域、期限和证据的综合判断。
