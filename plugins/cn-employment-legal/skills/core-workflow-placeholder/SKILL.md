# Core Workflow Placeholder

## Purpose

说明 `cn-employment-legal` 的 MVP 工作流边界，并提示后续可继续深化的技能方向。所有输出均为“律师审阅用草稿”。

## When to use

- 需要了解本插件当前能力边界时。
- 需要规划劳动用工后续验收或 alpha 修复时。
- 需要向律师、HR 或法务解释哪些事项已经进入 MVP，哪些仍待后续扩展时。

## Inputs expected

- 目标事项：劳动合同、员工手册、解除终止、裁员、竞业限制、外包派遣、内部调查、劳动争议材料。
- 使用角色：律师、企业法务、HR、管理层或合规负责人。
- 输出目标：审查意见、风险初筛、调查计划、证据包或管理层摘要。

## Workflow

1. 确认事项是否属于劳动用工 MVP 范围。
2. 引导用户选择具体技能：合同审查、员工手册审阅、解除风险初筛、竞业审查、外包派遣风险检查、内部调查计划或劳动争议证据包。
3. 提醒所有输出不得作为正式解除通知、员工手册、仲裁材料或调查结论直接使用。
4. 对不属于本插件范围的事项，建议转交相应律师团队或后续插件。

## Output format

- 当前可用技能清单。
- 适用事项和不适用事项。
- 推荐输入材料。
- 律师复核和升级提示。
- 后续验收建议。

## Quality checks

- 是否标注“律师审阅用草稿”。
- 是否避免正式法律结论。
- 是否要求对事实、证据、法律依据和地方规则进行人工核验。
- 是否提醒真实员工材料不得提交到公开仓库。

## Escalation / attorney review gate

任何涉及高风险或红旗风险的劳动用工事项，均应按共享升级矩阵交由主办律师、负责合伙人、企业法务或管理层复核，不得继续自动处理。

## Confidentiality notes

本占位技能不得接收真实员工个人信息、工资、社保、考勤、绩效、投诉举报、内部调查或争议材料。需要处理真实事项时，应在私有环境并按授权范围使用。

## Limitations

本技能只做导航和范围说明，不替代具体 MVP 技能，不提供法律意见，不确认解除、竞业、劳动关系或争议处理结论。
