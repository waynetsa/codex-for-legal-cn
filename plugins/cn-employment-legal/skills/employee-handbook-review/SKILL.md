# Employee Handbook Review

## Purpose

生成员工手册和规章制度审阅意见草稿，重点检查制度内容、民主程序、公示送达、考勤、请休假、加班、绩效、奖惩、重大违纪、保密、反骚扰、投诉举报和个人信息处理风险。

## When to use

- 企业制定或修订员工手册、考勤制度、绩效制度、奖惩制度时。
- HR 需要初步识别制度是否具备执行和证据留存基础时。
- 劳动争议前需要评估制度依据可用性时。

## Inputs expected

- 员工手册或制度文本。
- 适用员工范围、制定或修订背景、发布和签收方式。
- 已有民主程序、公示送达、培训记录和员工确认材料。

## Workflow

1. 标注“律师审阅用草稿”，说明不得直接作为正式员工手册发布。
2. 识别制度名称、适用员工范围和制度版本。
3. 分项审阅制定或修订程序、民主程序、公示送达、考勤、请休假、加班、绩效、奖惩、重大违纪、信息安全、保密、反骚扰、投诉举报和个人信息处理。
4. 将制度实体问题和程序问题分开列示。
5. 输出风险等级、建议修改方向、证据留存建议和升级事项。

## Output format

- 制度基本信息。
- 适用员工范围。
- 制定或修订程序提示：待律师核验。
- 民主程序和公示送达提示：待律师核验。
- 制度条款审阅表。
- 程序和证据留存清单。
- 风险等级总览。
- 建议修改方向。
- 升级事项。

## Quality checks

- 是否覆盖考勤、请休假、加班、绩效、奖惩、重大违纪、保密、信息安全、反骚扰和投诉举报。
- 是否把民主程序和公示送达写成待律师核验。
- 是否区分制度内容风险、程序风险和证据风险。
- 是否避免生成正式员工手册。

## Escalation / attorney review gate

涉及解除依据、重大违纪、绩效淘汰、工资扣减、罚款、个人信息处理、监控或投诉举报机制时，必须由劳动法律师复核。用于解除、处分或仲裁诉讼前必须升级。

## Confidentiality notes

不得提交真实员工投诉、考勤、绩效、处分、病假、工伤或内部调查材料到公开仓库。制度样例应虚构或脱敏。

## Limitations

本技能只生成制度审阅意见草稿，不确认制度已完成民主程序、公示送达或可作为解除依据。具体法律依据和地方口径均待律师核验。
