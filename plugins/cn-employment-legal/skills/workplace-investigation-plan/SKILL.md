# Workplace Investigation Plan

## Purpose

为内部调查事项生成律师审阅用草稿，帮助律师、HR、合规和管理层梳理调查范围、事实问题、证据、访谈安排、员工个人信息保护、保密和反报复要求。

## When to use

- 员工涉嫌违纪、舞弊、骚扰、利益冲突、数据泄露、商业秘密泄露或违反信息安全制度时。
- 企业收到投诉举报、匿名线索、客户投诉或监管问询前需要先做内部事实整理时。
- 需要设计调查计划、访谈提纲和证据保全安排，但尚不能作出责任认定时。

## Inputs expected

- 调查事项、涉及人员脱敏信息、线索来源、已知事实、时间线和相关制度。
- 证据材料清单：邮件、聊天记录、系统日志、门禁记录、文件下载记录、报销单据、访谈记录等。
- 拟访谈对象、调查时间安排、保密要求和管理层关注点。

## Workflow

1. 标注“律师审阅用草稿”，说明不得直接作为调查结论、处分依据或对外文件。
2. 使用脱敏字段列明调查事项、涉及人员、调查目标和调查范围。
3. 梳理事实问题清单、证据清单和待补材料。
4. 将访谈提纲拆分为开放问题、封闭确认、证据确认、风险告知、记录确认和反报复提示。
5. 单独提示员工个人信息和隐私保护、保密、反报复、电子数据留存和外部律师介入场景。
6. 对涉及骚扰、商业秘密泄露、数据泄露、多人投诉、高管参与、可能刑事或行政风险的事项触发升级。

## Output format

- 律师审阅用草稿声明。
- 调查事项摘要表：调查事项、涉及人员、调查目标、调查范围、风险等级。
- 事实问题清单。
- 证据清单和待补材料。
- 结构化访谈提纲：访谈对象、开放问题、封闭确认、证据确认、风险告知、记录确认、反报复提示。
- 个人信息和隐私保护提示。
- 保密和反报复提示。
- 调查程序风险。
- 调查报告结构草稿。
- 是否需要外部律师介入。
- 升级事项。

## Quality checks

- 是否使用脱敏人员字段。
- 是否避免作出员工违纪、骚扰、舞弊、泄密或责任认定结论。
- 是否把访谈问题拆分为开放问题、封闭确认、证据确认、风险告知和记录确认。
- 是否提示个人信息、隐私、保密、反报复和电子数据保全。
- 是否把高风险事项进入升级事项。

## Escalation / attorney review gate

涉及骚扰、歧视、报复、商业秘密泄露、数据泄露、高管参与、多人投诉、可能刑事风险、可能行政监管风险、群体性事件或媒体舆情时，必须升级给律师、合伙人、HR 负责人和管理层复核。

## Confidentiality notes

不得提交真实员工姓名、身份证件、联系方式、病历、薪酬、绩效、投诉举报材料、系统日志原文或未脱敏访谈记录。调查材料应在私有环境中处理。

## Limitations

本技能不作员工责任认定，不生成正式调查报告、处分决定、解除通知或对外声明。法律依据、证据可采性和处理措施均待律师核验。
