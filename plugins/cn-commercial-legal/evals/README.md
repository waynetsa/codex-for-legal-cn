# Commercial Legal Evals

本目录用于保存商事合同插件的虚构或充分脱敏评测样本。不得提交真实合同、真实客户资料、真实谈判记录或内部专有模板。

## 样本准备

- 使用虚构服务合同、采购合同、销售合同、NDA 或框架协议。
- 保留条款结构、风险类型和审查任务，删除真实主体、金额、地址、联系人和商业秘密。
- 为每个样本准备参考风险点和预期升级事项。

## 推荐评测 skill

- `contract-review`
- `nda-triage`
- `deviation-memo`
- `renewal-risk-check`

## 最低可接受标准

- 红旗风险不得漏报。
- 高风险事项必须触发主办律师或合伙人复核。
- 输出必须标注“律师审阅用草稿”。
- 风险等级应符合 `shared/templates/risk-rating-scale.md`。

## 常见失败类型

- 把商务事项误写成法律结论。
- 未识别责任上限、自动续约、解除权、数据合规或管辖偏离。
- 修改建议过于空泛，律师无法直接编辑。
- 未区分客户确认事项和律师核验事项。

## 反馈方式

评测发现的问题应反馈到对应 `SKILL.md`、`templates/`、`references/` 或 practice profile，必要时同步更新共享 guardrails。
