# Contract Review

## Purpose

生成商业合同审查备忘录、风险等级表、逐条审查意见和客户简明摘要。

## When to use

用于脱敏合同文本、条款摘录或对方修订稿的初步审查。

## Inputs expected

- 脱敏合同文本或条款摘录
- 我方身份、交易背景、谈判阶段和金额区间
- practice-profile.md 或客户 playbook
- 重点关注条款、历史谈判记录、客户已确认的商务底线

## Workflow

1. 确认文件信息、版本、我方身份和合同类型；无法判断时列为待确认。
2. 抽取主体、授权、标的、价款税费、交付验收、付款、发票、违约、责任限制、赔偿、解除、保密、知识产权、数据、个人信息、反商业贿赂、争议解决、续约终止等关键条款。
3. 依据 practice profile 标注低、中、高、红旗。
4. 逐条写明问题说明、对我方影响、建议处理、替代表述占位和是否升级。
5. 对法律依据位置写“待律师核验法律依据”或“建议律师检索确认”。
6. 单独列出待客户确认的商务事项和可直接给客户看的简明摘要。

## Output format

必须包含：文件信息、我方身份判断、合同类型判断、关键条款摘要、风险等级总览、逐条审查意见、建议修改方向、建议替代表述占位、待律师核验法律依据、待客户确认的商务事项、需主办律师或合伙人升级事项、可直接给客户看的简明摘要。风险表字段：风险编号｜条款位置｜条款主题｜风险等级（低/中/高/红旗）｜问题说明｜对我方影响｜建议处理｜是否需要升级｜待确认事项。

## Quality checks

- 输出首页或标题必须标注“律师审阅用草稿”。
- 不得虚构法律依据、案例、法规条文编号、法院观点或监管口径。
- 无法核验来源时，写“待律师补充法律依据”“待律师核验法律依据”或“建议律师检索确认”。
- 必须区分事实、风险、建议、待确认事项。
- 每条风险必须能追溯到合同条款位置或输入材料来源。
- 替代表述只能作为占位草稿，不得标注为最终可用条款。

## Escalation / attorney review gate

红旗风险、高额违约责任、无限责任、单方解除严重不利、排他或竞业、核心知识产权归属、个人信息或重要数据处理、境外管辖、重大合规承诺必须提交主办律师或合伙人复核。

## Confidentiality notes

仅处理脱敏材料。不得把真实客户、真实案件、商业秘密、个人信息、身份证件信息、联系方式、银行账户或密钥写入公开仓库、示例、模板或提交记录。

## Limitations

不能替代完整合同审查、商业谈判授权、税务意见、数据合规专项意见或跨境法域意见。
