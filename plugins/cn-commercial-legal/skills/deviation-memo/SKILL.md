# Deviation Memo

## Purpose

整理对方合同或修订稿相对于律所、客户或项目 playbook 的偏离点。

## When to use

用于客户有标准条款、合同审查口径或历史谈判底线的项目。

## Inputs expected

- 脱敏合同文本或修订稿
- 团队或客户 playbook
- 我方身份、谈判阶段、已获授权让步范围
- 审批人或升级规则

## Workflow

1. 读取 playbook 标准口径，建立条款主题和标准位置。
2. 逐项比对合同当前表述，识别缺失、弱化、加重、扩大、冲突、模糊等偏离类型。
3. 评估偏离严重程度和可接受/不接受理由。
4. 生成建议谈判语言，保持为草稿占位。
5. 标注审批人、最终处理状态和待客户确认事项。

## Output format

表格字段必须包含：偏离条款、playbook 标准口径、合同当前表述、偏离类型、偏离严重程度、可接受理由、不接受理由、建议谈判语言、审批人、最终处理状态。

## Quality checks

- 输出首页或标题必须标注“律师审阅用草稿”。
- 不得虚构法律依据、案例、法规条文编号、法院观点或监管口径。
- 无法核验来源时，写“待律师补充法律依据”“待律师核验法律依据”或“建议律师检索确认”。
- 必须区分事实、风险、建议、待确认事项。
- 如果 playbook 未提供，不得编造客户标准口径，应写“待客户或负责律师补充 playbook”。

## Escalation / attorney review gate

严重偏离、超出授权让步范围、改变责任上限、改变争议解决、影响核心商业模式或合规承诺的事项必须升级。

## Confidentiality notes

仅处理脱敏材料。不得把真实客户、真实案件、商业秘密、个人信息、身份证件信息、联系方式、银行账户或密钥写入公开仓库、示例、模板或提交记录。

## Limitations

不能替代客户内部审批流程或合伙人对偏离接受性的判断。
