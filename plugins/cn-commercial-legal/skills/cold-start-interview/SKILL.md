# Cold-Start Interview

## Purpose

在处理商事合同事项前，收集背景信息、适用法域、合同类型、客户角色、输出用途和律师复核要求。

## When to use

首次接触合同审查、NDA 初筛、供应商合同、销售合同、采购合同、续约或解除风险事项时使用。

## Inputs expected

- 脱敏合同或摘要。
- 客户角色和交易背景。
- 合同类型、金额、期限和关键商业目标。
- 适用法域假设；默认中国大陆法律语境。

## Workflow

1. 确认事项类型和客户目标。
2. 询问合同状态、谈判阶段和对方角色。
3. 确认重点条款、风险偏好和输出格式。
4. 标记缺失信息和律师复核人。

## Output format

输出“律师审阅用草稿”，包括事实、风险、建议、待确认事项和下一步。

## Quality checks

- 不补造事实。
- 不虚构法律依据。
- 未确认事项写入待确认清单。

## Escalation / attorney review gate

任何对外发送、提交、签署或作为法律意见依赖的内容，必须由合格律师复核。

## Confidentiality notes

不得包含真实客户、交易对手、自然人身份信息、商业秘密或未公开交易信息。

## Limitations

本 skill 只收集背景，不直接给出最终法律结论。
