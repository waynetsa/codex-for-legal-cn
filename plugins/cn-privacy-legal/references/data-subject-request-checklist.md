# 用户个人信息请求响应检查清单

> 律师审阅用草稿。不构成正式用户答复。响应期限、拒绝情形和法律依据均需待律师核验。

## 请求类型

- 查询。
- 复制。
- 更正。
- 删除。
- 撤回同意。
- 注销账号。
- 解释说明。
- 投诉处理。

## 处理步骤

- 登记请求渠道、时间、请求类型和材料。
- 按最小必要原则进行身份核验。
- 判断是否涉及敏感个人信息、未成年人、第三方权益或安全事件。
- 分配内部责任部门：客服、产品、技术、法务、合规、IT / 安全。
- 查询系统操作路径和影响范围。
- 形成答复草稿并由律师或合规负责人复核。
- 留存处理记录、复核记录和答复记录。

## 升级事项

- 请求人身份无法确认或存在冒用风险。
- 请求涉及批量数据、敏感个人信息、未成年人信息、账号争议。
- 可能影响第三方权益、商业秘密、诉讼证据或监管事项。
- 需要拒绝、限制响应或延长处理期限。

## 内部交接检查点

| 环节 | 责任团队 | 检查点 |
| --- | --- | --- |
| 受理 | 客服 | 请求类型、渠道、时间、账号占位符、工单编号 |
| 身份核验 | 客服 / 安全 | 是否最小必要、是否存在冒用风险、是否需要升级 |
| 数据定位 | 产品 / 技术 | 涉及系统、字段、保存期限、第三方或备份数据 |
| 法务复核 | 法务 / 合规 | 响应期限、限制或拒绝情形、是否影响第三方权益 |
| 系统操作 | 技术 / 产品 | 查询、复制、更正、删除、注销或关闭推送路径 |
| 答复发送 | 客服 / 法务 | 是否使用经复核提纲，是否保留发送记录 |
| 归档 | 合规 / 法务 | 请求材料、核验记录、处理记录、答复记录 |
