# 个人信息类型和敏感个人信息判断提示

> 律师审阅用草稿。不构成法律意见。分类仅用于工作流提醒，具体判断待律师核验。

## 常见个人信息类型

| 类别 | 常见示例 | 风险提示 |
| --- | --- | --- |
| 基本身份信息 | 姓名、昵称、账号标识 | 公开样例只使用虚构或占位信息 |
| 联系方式 | 电话、邮箱、收货联系信息 | 不得写真实联系方式 |
| 账号和认证信息 | 用户 ID、登录记录、权限角色 | 注意访问权限和日志留痕 |
| 设备和网络信息 | 设备标识、IP、浏览器、操作日志 | 注意 SDK 和第三方处理 |
| 位置信息 | 粗略位置、精确位置、常用地址 | 精确位置通常需升级核验 |
| 交易信息 | 订单、支付状态、会员权益 | 注意保存期限和访问范围 |
| 内容和行为数据 | 浏览、点击、收藏、评论、搜索 | 注意画像、推荐和营销用途 |
| 员工信息 | 招聘、考勤、绩效、薪酬相关材料 | 注意内部权限和最小必要 |
| 未成年人信息 | 年龄段、监护人相关信息 | 默认升级核验 |

## 敏感个人信息判断提示

- 是否可能影响人身、财产、人格尊严或重大权益。
- 是否涉及证件、金融账户、健康、生物识别、精确位置、行踪轨迹、未成年人等。
- 是否用于自动化决策、精准营销、风控画像、招聘或绩效等高影响场景。
- 不确定时写“待律师核验”，并列入升级事项。

## 输出提醒

- 不要在模板或样例中写真实身份证件号码、手机号、住址、银行账户、健康信息、未成年人信息或生物识别信息。
- 必须区分“事实材料显示”和“律师判断待核验”。
