# 核心工作流占位说明

## Purpose

说明 `cn-privacy-legal` 已从骨架进入最小可用版本，当前能力拆分为个人信息处理活动梳理、隐私政策审阅、数据处理协议审查、影响评估、数据出境初筛和用户请求响应流程。所有输出均为“律师审阅用草稿”。

## When to use

- 需要了解本插件当前技能边界。
- 准备新增后续技能但尚未进入端到端验收。
- 律师、法务或合规负责人需要判断应调用哪个隐私合规技能。

## Inputs expected

- 事项类型和业务场景。
- 是否涉及 App、小程序、网站、平台、AI 工具、HR、营销、客服、第三方 SDK 或跨境供应商。
- 需要生成的草稿类型。

## Workflow

1. 判断事项属于处理活动台账、隐私政策、数据处理协议、影响评估、数据出境初筛还是用户请求响应。
2. 推荐对应技能。
3. 提醒用户只使用虚构或脱敏材料。
4. 标注该插件尚未完成端到端验收，真实项目必须由律师复核。

## Output format

- 律师审阅用草稿声明
- 推荐技能
- 适用事项
- 输入材料清单
- 输出类型
- 必须升级事项
- 保密和复核提示

## Quality checks

- 是否没有把占位说明写成法律意见。
- 是否没有建议上传真实个人信息或客户秘密。
- 是否明确正式制度、正式隐私政策、正式评估报告和监管提交材料不得直接由 AI 输出生成。

## Escalation / attorney review gate

如事项涉及敏感个人信息、未成年人信息、数据出境、监管调查、安全事件、大规模用户投诉或重大商业上线，应直接升级主办律师或合伙人。

## Confidentiality notes

公开仓库不得保存真实客户、真实用户、真实员工、真实系统、真实供应商、真实日志、真实合同或真实出境材料。

## Limitations

本技能只用于路由和规划，不替代任何具体隐私合规技能，也不提供法律结论。
