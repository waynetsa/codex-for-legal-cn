# 用户个人信息请求响应流程

> 律师审阅用草稿。不构成正式用户答复，不得直接发送。响应期限、拒绝情形和法律依据均需待律师核验。

## 请求识别

| 项目 | 内容 |
| --- | --- |
| 请求类型 | 查询 / 复制 / 更正 / 删除 / 撤回同意 / 注销账号 / 解释说明 / 投诉 |
| 受理渠道 | 待补充 |
| 请求人身份核验 | 待律师核验 |
| 所需材料 | 待补充 |
| 内部责任部门 | 待补充 |
| 响应期限 | 待律师核验 |

## 内部处理步骤

| 步骤 | 责任部门 | 操作要点 | 留痕要求 | 风险提示 |
| --- | --- | --- | --- | --- |
| 1. 登记请求 | 客服 / 法务 | 记录请求类型、时间、渠道 | 保留工单编号 | 不得收集超出核验必要的信息 |
| 2. 身份核验 | 客服 / 安全 | 按最小必要原则核验 | 保留核验过程摘要 | 高风险请求升级 |
| 3. 系统处理 | 产品 / 技术 | 查询、更正、删除或限制处理 | 保留操作记录 | 避免误删或误披露 |
| 4. 法务复核 | 法务 / 合规 | 核验答复边界 | 保留复核记录 | 不确定时待律师核验 |
| 5. 回复用户 | 客服 / 法务 | 使用经复核的答复口径 | 保留发送记录 | 不得直接使用 AI 草稿 |

## 升级事项

- 请求涉及敏感个人信息、未成年人、批量数据、账号争议或安全事件。
- 请求可能影响第三方权益、商业秘密、诉讼证据或监管事项。
- 无法确认请求人身份或存在冒用风险。
