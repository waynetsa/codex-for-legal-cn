# Eval Rubric

所有评测材料必须虚构或充分脱敏。评分结果只评价工作流输出质量，不代表法律结论正确性。

## 评分标准

| 分数 | 含义 |
| --- | --- |
| 1 | 不可用，存在重大遗漏、误导或格式无法复核 |
| 2 | 勉强可参考，但需要大量律师重做 |
| 3 | 基本可用，仍有明显补充和修正空间 |
| 4 | 良好，可显著减少律师整理时间 |
| 5 | 优秀，结构清楚、来源可追踪、仅需少量律师编辑 |

## 合同审查评测维度

| 维度 | 评分关注点 |
| --- | --- |
| 重大风险识别 | 是否识别责任上限、解除、违约、付款、数据、保密、管辖等关键风险 |
| 条款分类准确性 | 是否正确区分主体、价款、交付、验收、责任、争议解决等主题 |
| 修改建议可执行性 | 建议是否能直接转化为谈判点或替代表述占位 |
| 风险等级一致性 | 是否符合 `risk-rating-scale.md` 和团队 profile |
| 是否误报 | 是否把普通表述误判为重大风险 |
| 是否漏报 | 是否遗漏样本中预设的重大风险 |
| 是否正确触发升级 | 是否按 `escalation-matrix.md` 标注主办律师、合伙人或客户决策 |
| 输出是否便于律师修改 | 是否结构化、简洁、保留事实来源和待确认事项 |

## 并购尽调评测维度

| 维度 | 评分关注点 |
| --- | --- |
| 资料摘要准确性 | 是否忠于资料室文件或文件清单 |
| 问题提取完整性 | 是否覆盖股权、治理、合同、资质、税务、劳动、诉讼、处罚等模块 |
| 重大性判断 | 是否说明重大性阈值、假设和待核验信息 |
| 披露清单可用性 | 是否能映射到协议条款占位和披露事实 |
| 交割条件完整性 | 是否识别交割前、交割日、交割后事项 |
| 引用来源可追踪性 | 是否保留文件名、版本、页码或引用占位 |
| 待追问问题质量 | 问题是否具体、可由客户或目标公司回答 |
| 风险优先级排序 | 是否突出红旗和高风险事项 |

## 诉讼案件管理评测维度

| 维度 | 评分关注点 |
| --- | --- |
| 事实时间线完整性 | 是否覆盖关键日期、事件、参与方和证据来源 |
| 证据目录结构 | 是否编号清楚、证明目的明确、关联争点 |
| 争点提炼质量 | 是否区分事实争点、法律争点和证明难点 |
| 证明目的表达 | 是否避免夸大证据证明力 |
| 三性提示准确性 | 是否提示真实性、合法性、关联性待核验点 |
| 待核实事项识别 | 是否列明证据缺口、事实矛盾和期限不确定 |
| 案件周报可读性 | 是否便于客户或团队理解进展与下一步 |
| 期限和升级事项识别 | 是否识别诉讼时效、保全、上诉、举证等关键期限 |
