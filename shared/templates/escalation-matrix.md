# 升级矩阵

| 层级 | 可处理事项 | 必须升级的触发条件 |
| --- | --- | --- |
| 初级律师可处理 | 格式整理、资料清单、低风险条款、模板字段补全 | 发现中风险以上事项、来源不明、客户授权不清 |
| 主办律师必须复核 | 中风险事项、常规合同修改、尽调问题归类、证据目录和争点表 | 高风险、红旗风险、对外发送、提交机构、关键期限 |
| 合伙人必须复核 | 高风险事项、重大合同偏离、重大交易红旗、诉讼策略和关键法律判断 | 红旗风险、重大声誉风险、监管调查、刑事风险 |
| 客户法务或业务负责人必须决策 | 商务让步、责任承担、交易条件、和解方案、费用结算 | 涉及客户商业判断、授权边界、预算或业务承诺 |
| 暂停并人工判断 | 资料可能真实敏感、法律依据无法核验、期限紧急、权限不足 | 不得继续自动处理，必须等待律师或合规负责人确认 |

## 典型升级场景

- 合同金额重大或超过团队 practice profile 设定阈值。
- 责任上限缺失、异常扩大、与保险或业务承受能力不匹配。
- 管辖、仲裁、适用法律或送达条款重大偏离团队口径。
- 涉及数据合规、个人信息、跨境传输或客户敏感资料。
- 并购项目出现重大红旗问题、交割条件缺失或披露口径不清。
- 诉讼时效、保全期限、上诉期限、举证期限临近或不确定。
- 证据真实性、合法性、关联性存在重大争议。
- 可能涉及刑事、行政处罚、监管调查或重大声誉风险。
