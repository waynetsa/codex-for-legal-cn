# 输出质量检查清单

每次输出前，Codex 和使用者都应检查：

| 检查项 | 问题 |
| --- | --- |
| 草稿标识 | 是否明确标注“律师审阅用草稿” |
| 结构清晰 | 是否区分事实、风险、建议、待确认事项和升级事项 |
| 来源可追踪 | 是否列明事实来源、法律来源或待核验来源 |
| 法律依据 | 是否避免虚构法规、案例、条文编号和法院观点 |
| 敏感信息 | 是否避免真实客户、真实案件、个人信息、商业秘密和密钥 |
| 升级判断 | 是否根据 `escalation-matrix.md` 标注需复核或暂停事项 |
| 可编辑性 | 是否便于律师继续修改，而不是写成不可复核的结论 |
| 简洁性 | 是否使用表格、编号和短句，避免堆砌空泛描述 |
| 对外限制 | 是否提醒不得直接发送、提交、签署或依赖 |
