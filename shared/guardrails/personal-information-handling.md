# Personal Information Handling

## 最小必要原则

使用 Codex for Legal CN 时，只应提供完成当前工作所必需的最少信息。能用摘要、编号、占位符或脱敏字段完成的，不应提供原始个人信息。

## 不得上传或提交的信息

公开仓库、公开 issue、公开 PR 和示例材料不得包含：

- 身份证号、护照号、港澳台证件号等身份识别信息。
- 手机号、家庭住址、个人邮箱、即时通讯账号。
- 银行账户、支付账户、工资流水、财务账户。
- 健康信息、医疗记录、未成年人信息、生物识别信息。
- 精准定位、婚姻家庭、宗教、犯罪记录等敏感信息。
- 任何可与其他信息结合识别特定个人的材料。

## 示例材料脱敏方法

- 使用“张三（虚构）”“某员工 A”“供应商 B”等占位。
- 使用“证件号：已脱敏”“地址：某市某区”。
- 改写日期、金额、岗位、地点和关系链，避免组合识别。
- 删除文件元数据、图片 EXIF、批注、修订记录和隐藏表格。

## 何时需要授权

如在私有环境中处理真实个人信息，应确认客户授权、律所制度、项目授权范围和工具供应商处理边界。涉及个人信息出境、第三方工具处理、跨客户共享、外包处理或内部权限扩大时，必须由负责律师、合规负责人或客户确认。

## 中国法语境提醒

涉及个人信息保护时，应结合中国大陆现行规则、客户行业监管要求、数据处理目的、处理方式、保存期限和第三方接收方进行核验。本文不列举具体条文；如需引用法律依据，请写“待律师核验法律依据”并由律师检索确认。
