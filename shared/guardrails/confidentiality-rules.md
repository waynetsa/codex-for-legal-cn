# Confidentiality Rules

## 律所执业保密边界

法律服务材料通常包含客户秘密、案件策略、交易安排、谈判底线、证据材料和律师工作底稿。除非取得明确授权并符合律所制度，不得向无关人员、公开平台或公开仓库披露。

## 材料处理规则

- 客户资料：只在授权事项范围内使用，公开示例必须虚构或充分脱敏。
- 案件材料：不得公开案号、当事人、证据原文、诉讼策略、和解底线。
- 交易资料：不得公开交易结构、估值、投资人、目标公司、资料室文件或未公开商业信息。
- 律师工作底稿：内部批注、风险判断、谈判策略和复核记录不得进入公开仓库。
- 内部批注：对外发送前必须清除修订痕迹、批注、隐藏文本和元数据。

## 公开仓库边界

本公开仓库只能存放：

- 通用模板。
- 工作流程说明。
- 检查清单。
- 虚构样例。
- 充分脱敏且无法反向识别的样例。

禁止提交真实客户名、真实案件名、真实合同、真实证据、真实交易文件、真实个人信息、内部报价、密钥、token、Cookie 或私有连接配置。

## 使用场景区别

| 场景 | 可使用内容 | 注意事项 |
| --- | --- | --- |
| 本地个人环境 | 授权范围内的工作材料 | 不得误提交公开仓库 |
| 律所私有仓库 | 经批准的模板、脱敏样例、内部流程 | 需要权限控制和审计 |
| 公开仓库 | 模板、流程、虚构样例 | 不得包含任何可识别真实事项的信息 |

## 推荐脱敏步骤

1. 删除真实客户、对方、自然人、公司、法院、仲裁机构和项目名称。
2. 替换合同编号、案号、证件号、地址、联系方式、银行账户和邮箱。
3. 修改金额、日期、交易结构和行业特征，避免组合识别。
4. 删除附件、批注、修订记录、隐藏文本和文件元数据。
5. 由负责律师或知识管理负责人复核后再用于评测或示例。
