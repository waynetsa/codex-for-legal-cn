# Attorney Review Gate

> 本规则适用于 Codex for Legal CN 的所有插件、技能、模板和示例输出。

## 基本原则

所有法律相关输出均只能作为“律师审阅用草稿”。AI 输出不得直接作为法律意见、律师函、诉讼文书、交易文件、客户邮件或任何可被第三方依赖的正式结论。

## 必须人工复核的输出

- 合同审查意见、NDA 放行建议、偏离清单、续约或解除风险提示。
- 尽调问题清单、披露清单、交割清单、重大风险摘要。
- 案件 intake、事实时间线、证据目录、争点表、庭前准备提纲、案件周报。
- 任何包含法律依据、风险等级、责任判断、诉讼策略、交易条件或客户决策建议的内容。

## 必须经过执业律师或负责合伙人复核的行为

- 对客户、交易对手、法院、仲裁机构、监管机构或其他第三方发送材料。
- 向法院、仲裁机构、监管机构提交证据、申请、函件、说明或任何程序性材料。
- 签署、盖章、提交、出具法律意见、律师函、尽调报告、诉讼文书或交易文件。
- 对重大风险、红旗事项、诉讼时效、保全期限、上诉期限、监管调查、刑事风险或重大声誉风险作出判断。

## 客户邮件复核要求

对外发送客户邮件前，负责律师至少应检查：

- 邮件是否只包含经授权可披露的信息。
- 是否混入内部批注、未确认事实、未经核验的法律依据或谈判底线。
- 是否清楚标注需要客户确认或决策的事项。
- 附件是否为正确版本，且不含无关客户或其他项目材料。

## 机构提交前复核要求

向法院、仲裁机构或监管机构提交材料前，应由主办律师或负责合伙人确认：

- 程序期限、提交主体、提交方式和附件清单。
- 事实陈述、证据编号、证明目的和引用来源。
- 法律依据是否已经检索并核验。
- 客户授权、签章、委托手续和内部审批是否齐备。

## 建议的人工复核清单

| 检查项 | 复核问题 |
| --- | --- |
| 草稿属性 | 是否明确为“律师审阅用草稿” |
| 事实来源 | 是否来自客户材料、公开来源或律师确认 |
| 法律依据 | 是否可追溯；无来源是否标注“待律师核验” |
| 风险等级 | 是否符合 `shared/templates/risk-rating-scale.md` |
| 升级事项 | 是否符合 `shared/templates/escalation-matrix.md` |
| 保密合规 | 是否包含真实客户、案件、个人信息或商业秘密 |
| 对外使用 | 是否经过负责律师或合伙人批准 |
